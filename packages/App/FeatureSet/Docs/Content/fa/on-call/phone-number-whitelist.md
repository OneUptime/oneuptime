# فهرست سفید شماره تلفن برای اعلان‌های آنکال

برای اینکه مطمئن شوید اعلان‌های آنکال را دریافت می‌کنید، لطفاً شماره تلفن‌های زیر را در فهرست سفید قرار دهید:

- ‎+13022917020 (آمریکا)
- ‎+447427817020 (بریتانیا)

با افزودن این شماره‌ها به فهرست سفید خود می‌توانید مطمئن باشید که هیچ اعلان مهمی را از دست نمی‌دهید.
