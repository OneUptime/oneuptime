# راهنمای نصب روی Windows

OneUptime را به‌عنوان یک اپلیکیشن دسکتاپ روی Windows نصب کنید تا پایش و مدیریت حادثه کامل داشته باشید.

## روش‌های نصب

### روش ۱: Microsoft Edge (توصیه‌شده)

Edge بهترین یکپارچگی PWA روی Windows را با قابلیت‌های بومی فراهم می‌کند.

1. **OneUptime را در Edge باز کنید**

   - مرورگر Microsoft Edge را اجرا کنید
   - به نشانی نمونه OneUptime خود بروید
   - وارد حساب OneUptime خود شوید
   - منتظر بمانید تا صفحه کامل بارگذاری شود

2. **نصب اپلیکیشن**

   - در نوار نشانی به دنبال **آیکون نصب** (⊞) بگردید
   - روی دکمه **«Install OneUptime»** کلیک کنید
   - یا روی **منوی سه‌نقطه** → **Apps** → **Install this site as an app** بزنید

3. **سفارشی‌سازی نصب**

   - **نام اپلیکیشن**: در صورت تمایل تغییر دهید (پیش‌فرض: OneUptime)
   - **Start Menu**: انتخاب کنید به منوی Start افزوده شود یا نه
   - **نوار وظیفه**: گزینه سنجاق کردن به نوار وظیفه
   - **دسکتاپ**: ساخت میان‌بر روی دسکتاپ

4. **تکمیل نصب**
   - برای پایان روی **«Install»** کلیک کنید
   - OneUptime در پنجره اختصاصی خود باز می‌شود
   - آن را در منوی Start زیر برنامه‌های نصب‌شده پیدا کنید

### روش ۲: Google Chrome

Chrome پشتیبانی عالی از PWA به‌همراه یکپارچگی غنی دسکتاپ ارائه می‌دهد.

1. **OneUptime را در Chrome باز کنید**

   - Google Chrome را اجرا کنید
   - به نمونه OneUptime خود بروید
   - مطمئن شوید وارد شده‌اید
   - بگذارید صفحه کامل بارگذاری شود

2. **نصب از نوار نشانی**

   - در نوار نشانی به دنبال **آیکون نصب** (⊞) بگردید
   - روی **«Install OneUptime»** کلیک کنید
   - یا از منو استفاده کنید: **سه نقطه** → **More tools** → **Create shortcut**

3. **گزینه‌های نصب**

   - برای تجربه‌ای شبیه اپلیکیشن، **«Open as window»** را علامت بزنید
   - در صورت تمایل نام اپلیکیشن را تغییر دهید
   - روی **«Install»** یا **«Create»** کلیک کنید

4. **اجرای اپلیکیشن**
   - OneUptime را در منوی Start ویندوز پیدا کنید
   - یا از میان‌بر دسکتاپ اجرا کنید
   - اپلیکیشن در پنجره اختصاصی باز می‌شود

### روش ۳: Firefox

Firefox از نصب PWA با یکپارچگی پایه‌ای دسکتاپ پشتیبانی می‌کند.

1. **OneUptime را در Firefox باز کنید**

   - مرورگر Firefox را اجرا کنید
   - به نشانی OneUptime بروید
   - فرایند ورود را کامل کنید

2. **نصب PWA**
   - به دنبال **پیام یا بنر نصب** بگردید
   - یا روی **منو** → **Install** کلیک کنید
   - در صورت وجود، معادل **«Add to Home Screen»** را بزنید

### پیکربندی راه‌اندازی

1. **اجرای خودکار**: OneUptime را طوری تنظیم کنید که با Windows اجرا شود
   - روی نوار وظیفه راست‌کلیک کنید → Task Manager → Startup
   - در صورت تمایل OneUptime را فعال کنید
2. **اندازه پیش‌فرض**: اندازه و موقعیت دلخواه پنجره را تنظیم کنید

### تنظیمات اعلان

1. **اعلان‌های Windows**

   - Settings → System → Notifications & actions
   - OneUptime را پیدا کنید و ترجیحات هشدار را تنظیم کنید
   - اعلان‌های بنری را برای حوادث فعال کنید

2. **Focus Assist**
   - تنظیمات مزاحم نشوید را پیکربندی کنید
   - اعلان‌های حیاتی OneUptime را مجاز کنید
   - سطوح اولویت را برای نوع‌های مختلف هشدار تعیین کنید

## گزینه‌های پیشرفته نصب

## رفع اشکال

### مشکلات نصب

**دکمه نصب ظاهر نمی‌شود:**

```
Solutions:
1. Ensure you're using Edge or Chrome (recommended browsers)
2. Verify HTTPS connection to OneUptime instance
3. Clear browser cache and cookies
4. Update browser to latest version
5. Check if PWA requirements are met on server
6. Disable browser extensions temporarily
```

**نصب شکست می‌خورد یا از کار می‌افتد:**

```
Solutions:
1. Run browser as administrator
2. Check Windows User Account Control (UAC) settings
3. Ensure sufficient disk space (minimum 100MB)
4. Temporarily disable antivirus software
5. Clear browser data completely
6. Restart Windows and try again
```

**اپلیکیشن در منوی Start ظاهر نمی‌شود:**

```
Solutions:
1. Search for "OneUptime" in Windows search
2. Check if installed under different name
3. Look in "Recently added" apps section
4. Reinstall and ensure "Add to Start Menu" is checked
5. Manually create shortcut if necessary
```

### مشکلات اعلان

**اعلان‌های Windows کار نمی‌کنند:**

```
Solutions:
1. Windows Settings → System → Notifications & actions
2. Enable notifications for OneUptime
3. Check Focus Assist settings
4. Ensure notification permissions in OneUptime
5. Test with simple notification first
```

## حذف نصب

### حذف کامل

1. **روش تنظیمات Windows**

   - Settings → Apps → Apps & features
   - «OneUptime» را جستجو کنید
   - روی آن کلیک کنید و «Uninstall» را بزنید

2. **روش مرورگر**

   - Edge/Chrome را باز کنید
   - به edge://apps/ یا chrome://apps/ بروید
   - OneUptime را پیدا کنید
   - روی گزینه‌ها → Uninstall کلیک کنید

3. **روش منوی Start**
   - در منوی Start روی OneUptime راست‌کلیک کنید
   - «Uninstall» را انتخاب کنید
   - حذف را تأیید کنید

## به‌روزرسانی و نگهداری

### به‌روزرسانی خودکار

- PWA مربوط به OneUptime وقتی آنلاین باشد به‌صورت خودکار به‌روزرسانی می‌شود
- به دخالت دستی نیازی نیست
- به‌روزرسانی‌ها با راه‌اندازی مجدد بی‌درنگ اعمال می‌شوند
- وصله‌های حیاتی بی‌درنگ منتشر می‌شوند
