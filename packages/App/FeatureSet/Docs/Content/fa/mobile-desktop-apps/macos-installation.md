# راهنمای نصب روی macOS

‏OneUptime را به‌عنوان برنامه‌ای بومی روی رومیزی macOS نصب کنید تا مانیتورینگ و مدیریت حادثه روان باشد.

## روش‌های نصب

### روش ۱: Safari (توصیه‌شده برای macOS)

‏Safari یکپارچه‌سازی عالی PWA با قابلیت‌های بومی macOS ارائه می‌دهد.

1. **باز کردن OneUptime در Safari**

   - مرورگر Safari را اجرا کنید
   - به نشانی نمونه OneUptime خود بروید
   - به حساب OneUptime خود وارد شوید
   - منتظر بمانید صفحه کاملاً بارگذاری شود

2. **نصب PWA**

   - در نوار منو روی **File** کلیک کنید
   - گزینه **"Add to Dock"** را برگزینید (macOS Sonoma به بالا)
   - یا در نوار نشانی دنبال **آیکن نصب** بگردید
   - جایگزین: **File** → **"Add to Home Screen"** (macOS قدیمی‌تر)

3. **سفارشی‌سازی نصب**

   - **App Name**: در صورت تمایل تغییرش دهید (پیش‌فرض: OneUptime)
   - **Dock**: افزودن به Dock را برگزینید
   - **Launchpad**: برای دسترسی آسان به Launchpad اضافه کنید

4. **اجرای برنامه**
   - ‏OneUptime را در Dock، Launchpad یا پوشه Applications بیابید
   - برای اجرا در پنجره‌ای اختصاصی کلیک کنید
   - برنامه مستقل از مرورگر Safari اجرا می‌شود

### روش ۲: Google Chrome

‏Chrome پشتیبانی استوار از PWA با یکپارچه‌سازی عالی رومیزی ارائه می‌دهد.

1. **باز کردن OneUptime در Chrome**

   - ‏Google Chrome را اجرا کنید
   - به نمونه OneUptime خود بروید
   - مطمئن شوید وارد شده‌اید
   - بگذارید صفحه کامل بارگذاری شود

2. **نصب از راه منو**

   - در نوار نشانی دنبال **آیکن نصب** (⊞) بگردید
   - روی **"Install OneUptime"** کلیک کنید
   - یا از **منوی Chrome** → **More tools** → **Create shortcut** استفاده کنید

3. **گزینه‌های نصب**

   - برای تجربه برنامه بومی، **"Open as window"** را تیک بزنید
   - در صورت نیاز نام برنامه را سفارشی کنید
   - روی **"Install"** یا **"Create"** کلیک کنید

4. **دسترسی به برنامه**
   - ‏OneUptime را در پوشه Applications بیابید
   - یا از راه جستجوی Spotlight به آن برسید
   - برای دسترسی سریع به Dock سنجاق کنید

### روش ۳: Microsoft Edge

‏Edge پشتیبانی محکمی از PWA با یکپارچه‌سازی خوب macOS ارائه می‌دهد.

1. **باز کردن OneUptime در Edge**

   - ‏Microsoft Edge را اجرا کنید
   - به نشانی OneUptime بروید
   - فرایند ورود را کامل کنید

2. **نصب برنامه**
   - روی **منوی سه‌نقطه** → **Apps** → **Install this site as an app** کلیک کنید
   - یا در نوار نشانی دنبال اعلان نصب بگردید
   - در صورت تمایل نام برنامه را سفارشی کنید
   - روی **"Install"** کلیک کنید

### گزینه‌های سفارشی‌سازی

### Dock و Launchpad

1. **جایگاه در Dock**: OneUptime را به جایگاه دلخواهتان در Dock بکشید
2. **اندازه Dock**: اندازه آیکن را در ترجیحات Dock تغییر دهید
3. **سازماندهی Launchpad**: پوشه‌ای برای برنامه‌های مانیتورینگ بسازید
4. **اعلان‌های نشان‌دار**: شمار حادثه‌ها را روی آیکن Dock نشان دهید

### نوار منو و اعلان‌ها

1. **مرکز اعلان**

   - System Preferences → Notifications → OneUptime
   - سبک‌های هشدار و تحویل را پیکربندی کنید
   - برای نوع‌های مختلف حادثه سطح اولویت تنظیم کنید

2. **یکپارچه‌سازی نوار منو**
   - نوار منوی بومی برای PWAهای Safari
   - آیتم‌های منوی سفارشی برای کنش‌های پرتکرار
   - میان‌برهای صفحه‌کلید برای وظیفه‌های رایج

## رفع اشکال

### مشکل‌های نصب

**گزینه "Add to Dock" در Safari در دسترس نیست:**

```
Solutions:
1. Ensure macOS Sonoma (14.0) or later
2. Update Safari to latest version
3. Try alternative: File → Add to Home Screen
4. Clear Safari cache and try again
5. Use Chrome or Edge as alternative
```

**‏PWA نصب نمی‌شود یا فرو می‌ریزد:**

```
Solutions:
1. Check macOS version compatibility
2. Ensure sufficient disk space (100MB+)
3. Update browser to latest version
4. Clear browser cache and cookies
5. Temporarily disable browser extensions
6. Restart Mac and try installation again
```

**برنامه در Applications پدیدار نمی‌شود:**

```
Solutions:
1. Check Launchpad for OneUptime icon
2. Search with Spotlight (⌘+Space)
3. Look in browser's PWA management section
4. Try reinstalling with different browser
5. Check if installed under different name
```

### مشکل‌های اعلان

**اعلان‌های macOS کار نمی‌کنند:**

```
Solutions:
1. System Preferences → Notifications → OneUptime
2. Enable "Allow notifications"
3. Set appropriate alert style (banners/alerts)
4. Check Do Not Disturb settings
5. Verify OneUptime notification settings
6. Grant notification permissions when prompted
```

## حذف نصب

### حذف کامل

1. **روش پوشه Applications**

   - پوشه Applications را باز کنید
   - ‏OneUptime را بیابید
   - به Trash بکشید یا راست‌کلیک کنید → Move to Trash

2. **روش Dock**

   - در Dock روی OneUptime راست‌کلیک کنید
   - «Options» → «Remove from Dock» را برگزینید
   - سپس از پوشه Applications حذفش کنید

3. **مدیریت PWA در مرورگر**
   - **Chrome**: chrome://apps/ → یافتن OneUptime → Remove
   - **Edge**: edge://apps/ → یافتن OneUptime → Uninstall
   - **Safari**: صفحه مدیریت اختصاصی ندارد

### حذف نصب تمیز

همه داده‌های مرتبط را حذف کنید:

```bash
# Clear Safari PWA data (general website data)
rm -rf ~/Library/Safari/Databases
rm -rf ~/Library/Caches/com.apple.Safari

# Clear Chrome PWA data
rm -rf ~/Library/Application\ Support/Google/Chrome/Default/Web\ Applications

# Clear Edge PWA data
rm -rf ~/Library/Application\ Support/Microsoft\ Edge/Default/Web\ Applications
```

### به‌روزرسانی‌های خودکار

### فرایند به‌روزرسانی دستی

به‌روزرسانی برنامه را وادار کنید:

1. **‏PWAهای Safari**: درون مرورگر Safari تازه‌سازی کنید
2. **‏PWAهای Chrome**: روی برنامه راست‌کلیک کنید → Reload یا ⌘+R
3. **تازه‌سازی کامل**: برنامه را ببندید، مرورگر را دوباره باز کنید، به OneUptime بروید

### برنامه نگهداری

نگهداری منظم برای کارایی بهینه:

**هفتگی:**

- برنامه OneUptime را بازراه‌اندازی کنید
- اگر مشکل دارید حافظه نهان مرورگر را پاک کنید
- به‌روزرسانی‌های macOS را بررسی کنید

**ماهانه:**

- مصرف ذخیره‌سازی را مرور و در صورت نیاز پاک‌سازی کنید
- اگر مرورگرها خودکار به‌روز نمی‌شوند به‌روزرسانی کنید
- تأیید کنید تنظیمات اعلان هنوز کار می‌کنند

## یکپارچه‌سازی با قابلیت‌های macOS

### یکپارچه‌سازی با برنامه Shortcuts

میان‌برهای سفارشی برای OneUptime بسازید:

1. برنامه **Shortcuts** را باز کنید
2. یک **New Shortcut** بسازید
3. کنش **"Open App"** را اضافه کنید
4. گزینه **OneUptime** را برگزینید
5. برای فعال‌سازی صوتی به Siri اضافه کنید

### یکپارچه‌سازی با Automator

وظیفه‌های OneUptime را خودکار کنید:

1. **Automator** را اجرا کنید
2. یک **Application** یا **Workflow** بسازید
3. کنش **"Launch Application"** را اضافه کنید
4. ‏PWA در OneUptime را برگزینید
5. گام‌های خودکارسازی بیشتری اضافه کنید

### یکپارچه‌سازی با Terminal

‏OneUptime را از راه Terminal مدیریت کنید:

```bash
# Create alias for quick OneUptime launch
echo 'alias oneuptime="open -a \"OneUptime\""' >> ~/.zshrc

# Function to check if OneUptime is running
oneuptime_status() {
    if pgrep -f "OneUptime" > /dev/null; then
        echo "OneUptime is running"
    else
        echo "OneUptime is not running"
    fi
}
```

## امنیت و حریم خصوصی

### قابلیت‌های امنیتی macOS

1. **Gatekeeper**: مطمئن شوید نصب‌های PWA از منابع مورد اعتمادند
2. **System Integrity Protection**: از فایل‌های سامانه محافظت می‌کند
3. **FileVault**: برای محافظت از داده، دیسک را رمزگذاری کنید
4. **Keychain**: ذخیره‌سازی امن اعتبارنامه

### ملاحظات حریم خصوصی

1. **Location Services**: در صورت نیاز برای مانیتورینگ پیکربندی کنید
2. **دوربین/میکروفن**: در صورت نیاز دسترسی بدهید
3. **ضبط صفحه**: ممکن است برای برخی قابلیت‌های مانیتورینگ لازم باشد
4. **دسترسی شبکه**: از پیکربندی درست دیوار آتش مطمئن شوید

### بهترین شیوه‌ها

1. **به‌روزرسانی منظم**: macOS و مرورگرها را به‌روز نگه دارید
2. **احراز هویت قوی**: در صورت در دسترس بودن از Touch ID/Face ID استفاده کنید
3. **امنیت شبکه**: برای دسترسی مانیتورینگ از راه دور از VPN استفاده کنید
4. **پشتیبان‌گیری داده**: پشتیبان‌گیری منظم Time Machine داده PWA را هم دربر می‌گیرد
5. **مرور دسترسی‌ها**: دسترسی‌های داده‌شده را مرتب مرور کنید
