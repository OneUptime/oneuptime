# مانیتور گواهی SSL

پایش گواهی SSL به شما امکان می‌دهد اعتبار و انقضای گواهی‌های SSL/TLS روی وب‌سایت‌ها و سرویس‌هایتان را پایش کنید. OneUptime گواهی‌های شما را به‌صورت دوره‌ای بررسی می‌کند و پیش از انقضا یا در صورت تشخیص هر مشکلی به شما هشدار می‌دهد.

## نمای کلی

مانیتورهای گواهی SSL به نقاط پایانی HTTPS شما وصل می‌شوند و گواهی SSL/TLS را بررسی می‌کنند. این کار به شما امکان می‌دهد:

- تاریخ انقضای گواهی‌ها را پایش کنید
- گواهی‌های منقضی یا نزدیک به انقضا را تشخیص دهید
- گواهی‌های خودامضا را شناسایی کنید
- اعتبار گواهی را راستی‌آزمایی کنید
- از قطعی سرویس به‌خاطر گواهی منقضی جلوگیری کنید

## ساخت یک مانیتور گواهی SSL

1. در داشبورد OneUptime به **Monitors** بروید
2. روی **Create Monitor** کلیک کنید
3. نوع مانیتور را **SSL Certificate** انتخاب کنید
4. نشانی نقطه پایانی HTTPS موردنظر برای بررسی را وارد کنید
5. معیارهای پایش را در صورت نیاز پیکربندی کنید

## گزینه‌های پیکربندی

### نشانی

نشانی کامل HTTPS نقطه پایانی‌ای را که می‌خواهید گواهی SSL آن را پایش کنید وارد کنید (برای نمونه `https://example.com` یا `https://example.com:8443`).

## معیارهای پایش

می‌توانید معیارهایی پیکربندی کنید که تعیین کنند وضعیت گواهی شما بر چه پایه‌ای آنلاین، تضعیف‌شده یا آفلاین در نظر گرفته شود:

### انواع فیلتر در دسترس

| نوع فیلتر                    | توضیحات                                                          |
| ---------------------------- | ---------------------------------------------------------------- |
| گواهی معتبر است              | اینکه گواهی معتبر است یا نه (منقضی نشده، خودامضا نیست)           |
| گواهی خودامضا است            | اینکه گواهی خودامضا است یا نه                                     |
| گواهی منقضی شده است          | اینکه گواهی منقضی شده است یا نه                                   |
| گواهی معتبر نیست             | اینکه گواهی نامعتبر است یا نه                                     |
| تا انقضا (ساعت)              | تعداد ساعت‌های باقی‌مانده تا انقضای گواهی                        |
| تا انقضا (روز)               | تعداد روزهای باقی‌مانده تا انقضای گواهی                          |

### شرط‌های فیلتر

برای **گواهی معتبر است**، **گواهی خودامضا است**، **گواهی منقضی شده است** و **گواهی معتبر نیست**:

- **درست** — شرط برقرار است
- **نادرست** — شرط برقرار نیست

برای **تا انقضا (ساعت)** و **تا انقضا (روز)**:

- **بزرگ‌تر از** — انقضا بیش از مقدار مشخص‌شده فاصله دارد
- **کوچک‌تر از** — انقضا کمتر از مقدار مشخص‌شده فاصله دارد
- **بزرگ‌تر یا مساوی** — انقضا برابر یا بیش از مقدار مشخص‌شده فاصله دارد
- **کوچک‌تر یا مساوی** — انقضا برابر یا کمتر از مقدار مشخص‌شده فاصله دارد

### نمونه معیار

#### اگر گواهی ظرف ۳۰ روز منقضی می‌شود، تضعیف‌شده علامت بزن

- **نوع فیلتر**: تا انقضا (روز)
- **شرط فیلتر**: کوچک‌تر از
- **مقدار**: ۳۰

#### اگر گواهی منقضی شده است، آفلاین علامت بزن

- **نوع فیلتر**: گواهی منقضی شده است
- **شرط فیلتر**: درست

#### اگر گواهی خودامضا است هشدار بده

- **نوع فیلتر**: گواهی خودامضا است
- **شرط فیلتر**: درست

#### اگر گواهی نامعتبر است، آفلاین علامت بزن

- **نوع فیلتر**: گواهی معتبر نیست
- **شرط فیلتر**: درست

## بهترین شیوه‌ها

1. **چند آستانه تنظیم کنید** — وضعیت تضعیف‌شده را روی ۳۰ روز و آفلاین را روی ۷ روز پیش از انقضا بگذارید تا برای تمدید فرصت داشته باشید
2. **همه نقاط پایانی را پایش کنید** — اگر چند دامنه یا زیردامنه دارید، برای هر کدام یک مانیتور بسازید
3. **پورت‌های غیراستاندارد را فراموش نکنید** — سرویس‌هایی که HTTPS را روی پورت غیراستاندارد اجرا می‌کنند از قلم نیفتند
4. **پس از تمدید پایش کنید** — پس از تمدید یک گواهی، بررسی کنید که مانیتور معتبر بودن آن را تأیید می‌کند
