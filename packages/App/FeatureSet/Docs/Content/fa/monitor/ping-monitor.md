# مانیتور Ping

پایش Ping به شما امکان می‌دهد در دسترس بودن و پاسخ‌دهی هر میزبان یا آدرس IP را پایش کنید. OneUptime به‌صورت دوره‌ای درخواست ping به هدف شما می‌فرستد و بررسی می‌کند که آیا درست پاسخ می‌دهد یا نه.

## نمای کلی

مانیتورهای Ping با فرستادن درخواست‌های ICMP ping به یک میزبان، اتصال شبکه‌ای پایه را آزمایش می‌کنند. این کار به شما امکان می‌دهد:

- زمان کارکرد و در دسترس بودن میزبان را پایش کنید
- تأخیر شبکه و زمان پاسخ را دنبال کنید
- مشکلات اتصال را پیش از اثرگذاری بر سرویس‌هایتان تشخیص دهید
- در دسترس بودن سرورها و دستگاه‌های شبکه را راستی‌آزمایی کنید

## ساخت یک مانیتور Ping

1. در داشبورد OneUptime به **Monitors** بروید
2. روی **Create Monitor** کلیک کنید
3. نوع مانیتور را **Ping** انتخاب کنید
4. نام میزبان یا آدرس IP موردنظر برای پایش را وارد کنید
5. معیارهای پایش را در صورت نیاز پیکربندی کنید

## گزینه‌های پیکربندی

### نام میزبان یا آدرس IP برای Ping

نام میزبان یا آدرس IP هدفی را که می‌خواهید پایش کنید وارد کنید (برای نمونه `example.com` یا `192.168.1.1`). هم نام میزبان و هم آدرس IP پذیرفته می‌شود.

## معیارهای پایش

می‌توانید معیارهایی پیکربندی کنید که تعیین کنند میزبان شما بر چه پایه‌ای آنلاین، تضعیف‌شده یا آفلاین در نظر گرفته شود:

### انواع فیلتر در دسترس

| نوع فیلتر               | توضیحات                                                                  |
| ----------------------- | ------------------------------------------------------------------------ |
| آنلاین است              | اینکه میزبان به درخواست‌های ping پاسخ می‌دهد یا نه                        |
| زمان پاسخ (میلی‌ثانیه)  | زمان رفت‌وبرگشت درخواست ping به میلی‌ثانیه                                |
| از دست رفتن بسته (٪)    | درصد درخواست‌های ICMP echo که پاسخی نگرفته‌اند                            |
| نوسان (میلی‌ثانیه)      | انحراف معیار زمان رفت‌وبرگشت در میان بسته‌های فرستاده‌شده در یک بررسی     |
| وقفه درخواست            | اینکه درخواست ping منقضی شده است یا نه                                    |

### شرط‌های فیلتر

برای **آنلاین است** و **وقفه درخواست**:

- **درست** — شرط برقرار است
- **نادرست** — شرط برقرار نیست

برای **زمان پاسخ**، **از دست رفتن بسته** و **نوسان**:

- **بزرگ‌تر از** — مقدار از یک آستانه فراتر می‌رود
- **کوچک‌تر از** — مقدار از یک آستانه کمتر است
- **بزرگ‌تر یا مساوی** — مقدار روی آستانه یا بالاتر از آن است
- **کوچک‌تر یا مساوی** — مقدار روی آستانه یا پایین‌تر از آن است

**این معیار را در یک بازه زمانی ارزیابی کن** یک چک‌باکس جداگانه در فرم معیار است، نه یک شرط فیلتر. آن را روشن کنید تا به‌جای مقدار آخرین بررسی، یک مقدار تجمیعی مقایسه شود — که زیر **ارزیابی** انتخاب می‌شود (میانگین، جمع، بیشینه، کمینه، همه مقادیر، هر مقدار) در پنجره‌ای که با **در (دقیقه) گذشته** تعیین می‌کنید.

**همه مقادیر** فقط وقتی مطابقت پیدا می‌کند که پنجره واقعاً با داده پوشیده شده باشد. مانیتوری که تازه ساخته شده، یا مانیتوری که ثبت بررسی‌هایش متوقف شده، تاریخچه کافی برای اظهارنظر درباره N دقیقه گذشته ندارد، بنابراین معیار به‌جای مطابقت با تنها داده موجود، منتظر می‌ماند. **هر مقدار** تنظیم مناسب برای «همان لحظه که یک بررسی از حد گذشت به من بگو» است و همچنان بی‌درنگ فعال می‌شود.

**اگر داده‌ای نبود** تعیین می‌کند تا وقتی پنجره نمی‌تواند پشتیبان معیار باشد چه اتفاقی بیفتد:

- **نادیده بگیر** (پیش‌فرض) — معیار مطابقت پیدا نمی‌کند. برای هشداردهی معمولی روی آستانه از این استفاده کنید.
- **فعال کن** — نبود داده را خودِ مشکل در نظر بگیر. برای بررسی‌های ضربان‌گونه که سکوت خودش شکست است از این استفاده کنید.
- **صفر در نظر بگیر** — پنجره را به‌عنوان یک صفر مقایسه کن. برای شمارنده‌هایی که «هیچ رویدادی» واقعاً یعنی صفر از این استفاده کنید.

### نمونه معیار

#### اگر میزبان در دسترس نیست، آفلاین علامت بزن

- **نوع فیلتر**: آنلاین است
- **شرط فیلتر**: نادرست

#### هشدار اگر زمان پاسخ از ۲۰۰ میلی‌ثانیه بیشتر شود

- **نوع فیلتر**: زمان پاسخ (میلی‌ثانیه)
- **شرط فیلتر**: بزرگ‌تر از
- **مقدار**: ۲۰۰
