# آدرس‌های IP

پراب‌های OneUptime Cloud وب‌سایت‌ها، APIها و سرورهای شما را از مجموعه‌ای ثابت از آدرس‌های IP بررسی می‌کنند. اگر جلوی چیزی که پایش می‌کنید یک فایروال یا فهرست مجاز قرار دارد، این آدرس‌ها را مجاز کنید تا بررسی‌ها به مقصد برسند.

```mermaid title="فهرست مجاز کجا اعمال می‌شود"
flowchart LR
    P["پراب‌های OneUptime"] -->|"بررسی از IPهای فهرست‌شده"| F["فایروال شما"]
    F -->|"مجاز"| S["وب‌سایت، API یا سرور شما"]
```

## آدرس‌های IP برای مجاز کردن

ترافیک این آدرس‌ها را در فایروال خود مجاز کنید:

{{IP_WHITELIST}}

> [!NOTE]
> این آدرس‌ها ممکن است تغییر کنند. OneUptime پیش از تغییر به شما خبر می‌دهد. برای اینکه بدون دنبال کردن اطلاعیه‌ها به‌روز بمانید، هر بار که فایروال خود را به‌روز می‌کنید [فهرست را دریافت کنید](#دریافت-فهرست-با-برنامه).

## دریافت فهرست با برنامه

همین فهرست به‌صورت JSON و بدون نیاز به کلید API ارائه می‌شود، تا یک اسکریپت بتواند قواعد فایروال شما را هماهنگ نگه دارد:

```bash
curl -s https://oneuptime.com/ip-whitelist
```

```json
{
  "ipWhitelist": ["<list of IPs>"]
}
```

`ipWhitelist` آرایه‌ای است که هر عضو آن یک آدرس است. برای چاپ هر آدرس در یک خط، مثلاً برای دادن به یک اسکریپت فایروال:

```bash
curl -s https://oneuptime.com/ip-whitelist | jq -r '.ipWhitelist[]'
```

## OneUptime خودمیزبان

در نمونهٔ خودتان، این صفحه و نقطه پایانی `/ip-whitelist` آدرس‌های تنظیم `IP_WHITELIST` نمونه را نشان می‌دهند، که فهرستی جداشده با ویرگول است. آدرس‌هایی را بنویسید که پراب‌های خودتان بررسی‌هایشان را از آن‌ها می‌فرستند.

:::tabs
@tab Kubernetes
مقدار `ipWhitelist` نمودار Helm را تنظیم کنید:

```yaml title="values.yaml"
ipWhitelist: "203.0.113.1,203.0.113.2"
```
@tab Docker Compose
`config.env` این تنظیم را به برنامه نمی‌رساند. آن را در یک `docker-compose.override.yml` کنار `docker-compose.yml` به محیط سرویس `app` بیفزایید و سپس OneUptime را دوباره راه‌اندازی کنید:

```yaml title="docker-compose.override.yml"
services:
  app:
    environment:
      IP_WHITELIST: "203.0.113.1,203.0.113.2"
```
:::

وقتی چیزی تنظیم نشده باشد، این صفحه **No IP addresses configured.** را نشان می‌دهد و نقطه پایانی یک آرایهٔ خالی `ipWhitelist` برمی‌گرداند.
