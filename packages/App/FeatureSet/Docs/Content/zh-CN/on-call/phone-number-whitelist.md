# 电话号码白名单

在 OneUptime Cloud 上，值班短信和电话来自下列号码。请将它们加入手机的允许列表，以免呼叫被拦截、静音或被标记为骚扰。

## OneUptime Cloud 号码

| 号码 | 国家/地区 |
| --- | --- |
| +13022917020 | 美国（US） |
| +447427817020 | 英国（UK） |

## 在手机上允许这些号码

:::steps
1. 将两个号码作为同一个联系人保存到手机通讯录中，例如"OneUptime"。
2. 如果您使用勿扰模式、专注模式或其他静音模式，请允许该联系人的来电和消息。
3. 如果开启了来电拦截或骚扰过滤应用，或运营商的骚扰防护，请在那里也将两个号码标记为可信。
:::

> [!TIP]
> 在 **用户设置** > **通知方式** 中添加或验证电话号码时，会从这些号码给您发送验证码，因此这是检查它们能否送达的快捷方法。

## 呼叫来自其他号码时

在以下情况下，您的呼叫来自上述以外的号码：

- **您的项目使用自己的 Twilio 账户。** 当项目有一个设为项目默认的 Twilio 配置时（ **项目设置** > **通知** > **通知设置** > **Twilio 配置** ），发给项目成员的短信和电话会通过该账户、从其电话号码发出。请改为将这些号码加入白名单。
- **您使用自托管安装。** 短信和电话来自管理员配置的 Twilio 号码：项目的默认 Twilio 配置，或 **Admin Dashboard** > **设置** > **Call and SMS** 下适用于整个安装的配置。请向管理员询问应将哪些号码加入白名单。
