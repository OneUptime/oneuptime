# 监控器密钥

您可以使用密钥存储您在监控检查中想要使用的敏感信息。密钥经过加密并安全存储。

### 添加密钥

要添加密钥，请前往 OneUptime 控制台 -> 监视器 -> 设置 -> 密钥 -> 创建监控器密钥。

![创建密钥](/docs/static/images/CreateMonitorSecret.png)

为密钥设置名称和值，然后在**访问**步骤中选择哪些监视器可以使用它。在本例中，我们添加了一个 `ApiKey` 密钥。

**请注意**：密钥经过加密并安全存储。保存后密钥值不会再次显示——表格中不会，编辑表单中不会，通过 API 也不会。如果丢失了该值，需要从原始来源重新获取并再次设置。要轮换密钥，请使用该行上的 **更新密钥值** 按钮；无需删除后重新创建。

### 选择哪些监视器可以使用密钥

每个密钥都有以下三种访问选项之一：

- **所有监视器**：项目中的每个监视器都可以使用该密钥，包括您以后创建的监视器。适用于许多监视器共享的凭据。
- **特定监视器**：只有您选择的监视器可以使用该密钥。这是默认选项，在这些选项出现之前创建的密钥也按此方式工作。
- **带标签的监视器**：至少带有您所选标签之一的监视器可以使用该密钥。为监视器添加其中一个标签即可使其获得访问权限；移除该标签后，监视器在下次运行时将失去访问权限。

您可以随时通过密钥所在行的**编辑**更改选项。只会保留所选选项的列表：切换到**所有监视器**会清空密钥的监视器列表和标签列表；在**特定监视器**和**带标签的监视器**之间切换会清空您切换离开的那个列表。

密钥永远不会提供给其他项目中的监视器。

任何能够编辑可使用某个密钥的监视器的人，都可以把该密钥发送到该监视器连接的任何地址。对于**所有监视器**，这包括项目中所有能够创建或编辑监视器的人。对于**带标签的监视器**，还包括所有能够为监视器添加其中一个标签的人。

在 API 中，访问选项是 `monitorAccess` 字段：`All Monitors`、`Specific Monitors` 或 `Monitors With Labels`。`monitors` 和 `labels` 字段保存相应的列表。创建时未提供 `monitorAccess` 的密钥会使用 `Specific Monitors`。

### 使用密钥

您可以在以下监控类型中使用密钥：

- API（在请求头、请求体和 URL 中）
- 网站、IP、端口、Ping、SSL 证书（在 URL 中）
- 合成监控器、自定义代码监控器（在代码中）
- SNMP 监控器（在 community string、SNMPv3 认证密钥和加密密钥中）

![使用密钥](/docs/static/images/UsingMonitorSecret.png)

要使用密钥，请在您想使用密钥的字段中添加 `{{monitorSecrets.SECRET_NAME}}`。例如，在本例中，我们在请求头字段中添加了 `{{monitorSecrets.ApiKey}}`。

密钥在探针上注入，在合成监控器或自定义代码监控器脚本执行之前，`{{monitorSecrets.ApiKey}}` 等引用将在运行中的脚本内解析为解密后的值。

如果监视器引用了它无权使用的密钥，该引用将保持原样，不会被替换为值。

在保存之前测试监视器时，只会填入**所有监视器**可用的密钥，因为新监视器不在任何列表中，也还没有标签。保存监视器后，测试将使用该监视器可以使用的所有密钥。
