# 帮助和支持

把 OneUptime 提供的帮助指向你自己的团队：用户看到的支持邮箱、聊天和帮助页面，**提供反馈** 的去向，单点登录对需要邀请的人显示的内容，以及获取移动应用的提示。每一项都可以保留 OneUptime 自己的设置、指向你自己的地址或链接，或者隐藏。

:::cards
- [更改帮助的去向](#更改帮助的去向)：Admin Dashboard 中的一个页面。
- [每项设置会改变什么](#每项设置会改变什么)：每个位置、它的默认值和可选项。
- [提供反馈](#提供反馈)：用户所写内容发送到哪里。
- [登录消息](#登录消息)：应该向谁申请邀请。
:::

## 更改帮助的去向

:::steps
### 打开帮助和支持
在 Admin Dashboard 中打开 **设置**，然后在侧边菜单中打开 **帮助和支持**。

### 更改一个位置
选择它旁边的 **更改**，选择 **默认**、你自己的地址或链接，或者 **隐藏它**，然后选择 **保存**。**请求演示** 和 **报告错误或请求功能** 是开关，切换后立即保存。

### 检查用户看到的内容
帮助菜单和登录屏幕会在各自的设置旁显示预览。用户下次打开页面时就会看到更改。
:::

在你更改某个位置之前，它会显示 OneUptime 一直以来的内容，所以从未打开此页面的服务器看起来和以前完全一样。

## 每项设置会改变什么

| 设置 | 用户在哪里看到 | 默认 | 你自己的 |
| --- | --- | --- | --- |
| **支持邮箱** | 帮助 › **支持邮箱**、找不到页面时的 **联系支持团队**，以及错误屏幕请用户发送支持包的地址 | `support@oneuptime.com` | 一个电子邮件地址 |
| **聊天** | 帮助 › **在 Slack 上聊天** | OneUptime 的 Slack 社区 | 一个链接。Slack 或 Microsoft Teams 链接保留其名称；其他链接显示为 **与支持团队聊天** |
| **请求演示** | 帮助 › **请求演示** | 显示 | 只能隐藏 |
| **提供反馈** | 帮助 › **提供反馈**，以及搜索中的 **提供反馈** | 此服务器的管理员 | 一个电子邮件地址，或你自己的页面 |
| **帮助和支持** | 页脚中的 **帮助和支持**，以及登录页面上的 **联系方式** | `https://oneuptime.com/support` | 一个链接 |
| **报告错误或请求功能** | 产品菜单底部，以及反馈后提供的公开 GitHub 问题 | 显示 | 只能隐藏 |
| **获取移动应用** | **如何联系我**、值班设置、新成员在首页的第一步，以及 **项目设置** 中的 **移动应用** | App Store 和 Google Play | 你自己的页面，例如设备管理工具的公司门户 |
| **给需要邀请的人的消息** | 单点登录中显示 “You need to be invited.” 和 “No project access.” 的屏幕 | OneUptime 的句子 | 你自己的文字 |

除消息外，每项设置也都可以隐藏。链接以 `https://`、`http://` 或 `mailto:` 开头。其他任何类型的链接（包括 `javascript:`）都会被页面拒绝，服务器也会再次拒绝。

Admin Dashboard 自己的帮助菜单、页脚和产品菜单保留 OneUptime 的链接：它们面向此服务器的管理员，而管理员通过 OneUptime 获得服务器方面的帮助。

### 谁能看到你的链接

支持邮箱和 **帮助和支持** 链接也会显示在登录页面上，因此任何能打开这些页面的人都能看到它们。聊天链接和移动应用的页面只发送给已登录的用户：聊天链接通常是加入你工作区的邀请。

## 提供反馈

| 选项 | 会发生什么 |
| --- | --- |
| **默认** | 和以前一样：通过电子邮件发送到 **设置** › **电子邮件** 中设置的 **管理员通知电子邮件**；如果没有设置，则保留在 **反馈** 中供此服务器的管理员查看。在 OneUptime Cloud 上，它会发送给 OneUptime 团队。 |
| **电子邮件地址** | 通过此服务器的电子邮件设置发送到该地址，并附上此人的姓名和电子邮件地址，以便你的团队回复。此人会收到一份副本。 |
| **您自己的页面** | **提供反馈** 会在新标签页中打开它，例如你的服务台表单。OneUptime 不会发送任何内容。 |
| **隐藏“提供反馈”** | 任何地方都不提供 **提供反馈**。 |

在服务器无法发送电子邮件期间，选择电子邮件地址会隐藏 **提供反馈**，而不是接收一条无法送达你团队的消息，设置页面也会说明这一点。在 **设置** › **电子邮件** 中设置电子邮件后，**提供反馈** 会自动恢复。

OneUptime 提出的问题（例如引导式设置有多容易）不属于 **提供反馈**：它们的答案保留在 **反馈** 中，可以在那里用 **询问体验如何** 关闭。

## 登录消息

服务器自己的单点登录会拒绝两类人：没有账户的人（在身份提供商不创建账户时显示 “You need to be invited.”），以及账户不属于任何项目的人（“No project access.”）。两者都需要邀请，所以这两个屏幕都会显示你的消息，说明应该向谁申请以及如何联系他们：

```text
Ask the IT service desk to invite you to OneUptime:
it-help@example.com or https://help.example.com/oneuptime
```

- 消息是纯文本，最多 1000 个字符，不能包含 `<` 或 `>`。
- 每一行是一个段落，其中的链接和电子邮件地址会变成链接。
- 屏幕标题保持不变，移动应用显示同样的文字。

## 移动应用提示

使用你自己的页面时，每个获取移动应用的提示都会指向那里：为你的页面显示一个以其地址命名的二维码，步骤中仍会写明此服务器的地址供应用连接。隐藏时，完全没有提示：

- **获取移动应用** 会从新成员在首页的第一步中移除，而这些第一步仍会在此人可以被联系到、并且测试呼叫已送达后完成。
- **如何联系我** 和值班设置只提供浏览器。
- **移动应用** 会从 **项目设置** 中移除。
