# 리소스 및 그룹

리소스는 상태 페이지의 한 행입니다 — 방문자가 이해할 수 있는 이름과 현재 상태를 가지고, 선택적으로 가동 시간 숫자와 기록 차트를 함께 보여 주는 모니터(또는 모니터 그룹)죠. 그룹은 리소스를 담는 섹션이라서, 모니터 마흔 개짜리 페이지가 끝없는 목록 하나 대신 "API", "웹 앱", "데이터 파이프라인"으로 읽히게 해 줍니다.

둘 다 하나의 화면에서 만듭니다. 상태 페이지를 열고 사이드 메뉴에서 **리소스**를 고르세요(모니터 그룹이 활성화되지 않은 프로젝트에서는 항목이 **모니터**라고 표시됩니다). 그룹은 예전에 별도 페이지에 있었지만 이제는 아니며, 옛 `/groups` URL은 여기로 리디렉션됩니다.

이 부분만 제대로 하면 상태 페이지의 나머지는 장식입니다. 방문자는 "내 문제인가 저쪽 문제인가"를 이 행들에서 판단하므로, 고객이 여러분의 제품을 부르는 방식으로 이름을 붙이세요 — `prod-checkout-lb-healthcheck-us-east-1`이 아니라 **Checkout API**처럼요.

## 리소스 화면

화면은 둘로 나뉩니다. 왼쪽에는 페이지의 모든 그룹을 나열하는 탐색기가 있고, 오른쪽에는 선택한 그룹의 내용이 있습니다.

- **그룹 탐색기(왼쪽)** — 그룹 트리이며, 위에는 검색 상자(**Search groups...**)가, 아래에는 `3 groups · 12 resources` 같은 실시간 개수가 있습니다. 그룹이 화면에 다 들어가지 않으면 **Show N more of M** 버튼이 나머지를 펼칩니다.
- **Top of page** — 탐색기의 첫 번째 행입니다. 어떤 그룹에도 속하지 않은 리소스를 담으며, 툴팁이 그 뜻을 정확히 알려 줍니다. 방문자는 이들을 모든 그룹보다 위에서 가장 먼저 봅니다. 페이지에 그룹이 아예 없으면 오른쪽 창의 제목은 대신 **All resources**가 됩니다.
- **리소스 창(오른쪽)** — 선택한 그룹의 이름이 제목입니다. 헤더에는 **Edit Group**, 기본 동작인 **모니터 추가** 버튼, 그리고 **More actions** 오버플로가 있습니다.

카드 헤더 자체에는 버튼 두 개가 있습니다. **New Group**, 그리고 **Import groups from CSV**와 **새로고침**을 담은 점 세 개 오버플로입니다.

카드 설명은 페이지의 형태에 따라 달라집니다. 그룹이 있으면 이것이 방문자가 보는 전부라는 것과 왼쪽에서 그룹을 골라 그 안의 내용을 편집하라는 안내가 나옵니다. 아직 그룹이 없으면 긴 페이지를 섹션으로 나누도록 그룹을 만들라고 권합니다.

**빈 상태는 무엇을 해야 할지 알려 줍니다.** 비어 있는 그룹에는 **No monitors here yet**과 함께 **모니터 추가**, **Add Multiple**, 그리고 — 상태 페이지에 그룹이 아예 없을 때만 — **Create a Group**이 표시됩니다. 검색 결과가 없으면 **No resources match your search**가 나옵니다. 비어 있는 탐색기는 그룹이 긴 상태 페이지를 섹션으로 나누며 중첩할 수 있다고 안내합니다.

## 모니터 추가하기

리소스를 넣을 그룹(그룹 없는 행이라면 **Top of page**)을 고른 다음 **모니터 추가**를 클릭하세요. 모달 제목은 **Add a monitor to {group}**이고 **모니터 세부 정보**와 **고급** 두 단계로 되어 있습니다.

**모니터 세부 정보**에서는

- **모니터** — 프로젝트의 모니터 드롭다운이며 플레이스홀더는 **모니터 선택**입니다. 필수입니다.
- **표시 이름** — 필수입니다. 방문자가 읽는 텍스트이며 모니터 자체의 이름과 별개로 저장되므로, 모니터링을 건드리지 않고 여기서 이름을 바꿀 수 있습니다.
- **설명** — 선택 항목이며 행 아래에 표시되는 마크다운입니다. 이 서비스가 실제로 무엇을 하는지 한 문장으로 설명하기 좋습니다.

프로젝트에서 모니터 그룹이 활성화되어 있으면 드롭다운 아래에 **Add a Monitor Group instead.** 링크가 나옵니다 — 클릭하면 **모니터** 드롭다운이 **모니터 그룹** 드롭다운(**모니터 그룹 선택**)으로 바뀝니다. 링크는 **Add a Monitor instead.**로 뒤집혀서 되돌아갈 수 있습니다. 여러 점검을 하나로 묶어 페이지의 한 행으로 표현하고 싶을 때 모니터 그룹을 쓰세요.

### 여러 개를 한 번에 추가하기

**Add Multiple**(**More actions** 메뉴에서는 **Add multiple monitors**)은 **Add Multiple Monitors**를 엽니다. 같은 두 단계지만 첫 단계가 단일 드롭다운 대신 **모니터** 다중 선택이고, **고급**에서 고른 표시 옵션은 선택한 모든 모니터에 적용됩니다. 새 페이지를 채우는 가장 빠른 방법입니다.

## 리소스의 표시 옵션

**고급** 단계는 단일 추가 양식과 일괄 모달에서 동일합니다. 여기 있는 모든 것은 리소스 단위입니다 — 같은 그룹의 두 행을 서로 다르게 설정할 수 있습니다.

| 필드                                                    | 용도                                                                                            |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **툴팁**(`displayTooltip`)                           | 상태 페이지에서 리소스 옆에 표시되는 추가 텍스트입니다. 범위를 적기 좋습니다. "미국 및 EU 고객"처럼요. |
| **현재 리소스 상태 표시**(`showCurrentStatus`)   | 기본적으로 켜져 있습니다. 행 옆에 현재 상태 — 정상, 저하됨, 오프라인 — 를 보여 줍니다.           |
| **가동 시간 % 표시**(`showUptimePercent`)                  | 기본적으로 꺼져 있습니다. 리소스 옆에 가동 시간 비율을 보여 줍니다.                                    |
| **가동 시간 정밀도 선택**(`uptimePercentPrecision`)   | **가동 시간 % 표시**를 켜야만 나타납니다. 필수이며 기본값은 소수점 한 자리입니다.                                    |
| **상태 기록 차트 표시**(`showStatusHistoryChart`) | 기본적으로 켜져 있습니다. 리소스의 일별 가동 시간 기록 막대 차트를 보여 줍니다.                         |

첫 단계의 **표시 이름**(`displayName`)과 **설명**(`displayDescription`) 역시 표시 전용입니다 — 모니터 자체는 절대 바꾸지 않습니다.

## 가동 시간 비율과 기록 차트

**가동 시간 % 표시**와 **상태 기록 차트 표시**는 둘 다 다른 곳에 있는 설정에 의존합니다. 두 항목이 다루는 기간은 **상태 페이지 → 해당 페이지 → 고급 → 고급 설정**의 **가동 시간 기록 설정** 카드에 있는 **가동 시간 기록 표시(일 단위)**입니다. 1일에서 90일까지 받아들이며 기본값은 90입니다.

그러니 순서는 이렇습니다. 리소스마다 토글을 켜고, 그다음 페이지 전체에 적용될 기간을 한 번 설정하세요.

**정밀도는 판단의 문제입니다.** **가동 시간 정밀도 선택** 드롭다운은 `99% (No Decimal)`, `99.9% (One Decimal)`, `99.99% (Two Decimal)`, `99.999% (Three Decimal)`을 제공합니다. 소수점이 많으면 정밀해 보이지만 셋째 자리를 두고 논쟁을 부릅니다. SLA를 스리 나인으로 공표한다면 거기에 맞추고 그 이상은 두지 마세요.

그룹에는 이 토글들의 자체 사본이 있어서 — 아래를 보세요 — 그룹은 합산된 비율을 보여 주고 그 안의 개별 모니터는 조용히 있게 하거나, 반대로 할 수도 있습니다.

기록 차트 막대의 색상과 어떤 모니터 상태를 "다운"으로 셀지는 **개요 페이지** 브랜딩 화면에서 설정하며, [상태 페이지 브랜딩 및 도메인](/docs/status-pages/branding-and-domains)에서 다룹니다.

## 그룹

**New Group**을 클릭하면 **Create New Status Page Group**이 열립니다. 양식은 **그룹 세부 정보**, **레이아웃**, **고급** 세 단계입니다.

**그룹 세부 정보**:

- **그룹 이름**(`name`) — 필수입니다. 방문자가 보는 섹션 제목입니다.
- **그룹 설명**(`description`) — 선택 항목인 마크다운이며 제목 아래에 표시됩니다.
- **Parent Group**(`parentStatusPageGroupId`) — 선택 항목입니다. 그룹을 최상위에 두려면 **No parent group (top level)** 그대로 두세요.
- **기본적으로 상태 페이지에서 펼치기**(`isExpandedByDefault`) — 방문자에게 섹션이 펼쳐진 채로 시작할지 접힌 채로 시작할지입니다.

**고급**은 리소스 토글을 그룹 수준에서 그대로 반영합니다.

- **현재 그룹 상태 표시**(`showCurrentStatus`) — 기본적으로 켜져 있습니다. 그룹 제목 옆에 상태를 보여 줍니다.
- **가동 시간 % 표시**(`showUptimePercent`) — 기본적으로 꺼져 있으며, 켜면 **가동 시간 정밀도 선택**이 나타납니다.

편집도 같은 방식입니다. 창 헤더의 **Edit Group**이나 탐색기 행 메뉴의 **Edit group**이 **Edit Status Page Group**을 열고, **변경 사항 저장** 버튼으로 저장합니다.

창 헤더에는 현재 켜져 있는 설정이 칩으로 표시됩니다 — **Grid**, **Collapsed by default**, **Uptime %** — 그래서 양식을 열지 않고도 그룹이 어떻게 설정되어 있는지 볼 수 있습니다.

### 그룹 관리하기

탐색기의 행별 메뉴에는 **Edit group**, **Move up**, **Move down**, **ID 표시**, **Delete group**이 있습니다. 창의 **More actions** 오버플로에는 더 긴 형태의 같은 항목들이 있습니다 — **Edit this group**, **Add a sub group**, **Move group up**, **Move group down**, **Show group ID**, **새로고침**, **Delete this group**입니다. 이름 없이 저장된 그룹은 **Untitled group**으로 렌더링되는데, 뭔가 입력하려 했다는 좋은 신호죠.

## 그룹 중첩하기

그룹은 중첩할 수 있습니다. 자식 그룹에 **Parent Group**을 설정하거나, 탐색기의 **Add a sub group inside this group** 동작을 쓰세요. 양식의 도움말은 이것이 겨냥한 형태를 설명합니다 — Corporate Units › Region › Market 같은 구조 — 그리고 각 단계가 그 아래 모든 것의 상태와 가동 시간을 합산해 보여 준다고 알려 줍니다.

그룹에 자식이 있으면 리소스 창에 각 자식으로 바로 연결되는 **Sub groups** 칩 줄이 표시되므로, 탐색기로 돌아가지 않고도 계층을 따라 이동할 수 있습니다.

중첩은 큰 페이지에서 값을 합니다. 제품 안에 지역이 들어 있는 호스팅 업체나, 사업 단위 안에 시장이 들어 있는 소매업체처럼요. 모니터 열두 개짜리 페이지라면 평평한 한 단계가 더 친절합니다.

## 리스트 레이아웃과 그리드 레이아웃

**레이아웃** 단계는 그룹의 **보기 모드**(`viewMode`)를 설정하며, 이는 그룹이 공개적으로 렌더링되는 방식을 바꿉니다.

| 이렇게 하고 싶다면…                                                     | 이것을 고르세요                   |
| ------------------------------------------------------------------- | ---------------------- |
| 서비스를 한 행에 하나씩, 평범한 세로 목록으로 보여 주기                 | **List**(기본값) |
| 같은 서비스를 여러 지역이나 테넌트에 걸쳐 행렬로 보여 주기 | **Grid**               |

**Grid**를 고르면 네 개의 필드가 더 나타납니다.

- **행 축 레이블** — 행 차원의 이름이며 플레이스홀더는 `Service`입니다.
- **행 축 값** — 행 자체이며 **Add Row**로 하나씩 추가합니다(플레이스홀더 `e.g. Auth`).
- **열 축 레이블** — 열 차원이며 플레이스홀더는 `Region`입니다.
- **열 축 값** — **Add Column**으로 추가합니다(플레이스홀더 `e.g. US-East`).

그리드 그룹의 각 모니터는 셀에 배치되므로, 일괄 모달은 모니터와 함께 행과 열을 여러분이 정한 축 레이블로 물어봅니다.

**모니터를 추가하기 전에 축을 먼저 만드세요.** 행이나 열이 없는 그리드 그룹에는 축이 생기기 전까지 모니터를 놓을 자리가 없다는 주황색 안내가 **Set up the grid** 버튼과 함께 표시되고, 그렇게 할 때까지 **모니터 추가** 버튼은 감춰집니다.

## 방문자가 보는 순서 정하기

순서는 가나다순이 아니라 명시적이며, 세 곳에서 설정합니다.

- **그룹 안의 리소스** — 행을 끕니다. 창에도 그렇게 적혀 있습니다. **Drag a row to change the order visitors see**.
- **그룹끼리의 순서** — 탐색기 행 메뉴의 **Move up** / **Move down**, 또는 창 오버플로의 **Move group up** / **Move group down**.
- **그룹 없는 리소스** — 이들은 **Top of page**에 있고 언제나 모든 그룹 위에 렌더링되므로, 모두가 가장 먼저 확인하는 하나를 여기에 두세요.

**드래그가 꺼지는 경우가 두 가지 있습니다.** **Search in {group}...** 상자로 창을 필터링하면 순서 변경이 비활성화됩니다 — 창이 `N of M shown · drag to reorder is off while filtering`이라고 알려 주니 검색부터 지우세요. 그리고 그리드 그룹은 드래그 정렬을 아예 지원하지 않습니다. 위치가 행과 열 축에서 나오기 때문입니다.

가장 많이 물어보는 서비스를 맨 위에 두세요. 장애 중에 페이지를 찾아온 방문자는 대개 첫 화면까지만 읽습니다.

## CSV에서 그룹 가져오기

깊은 계층을 손으로 만드는 일은 지루합니다. 카드 헤더의 점 세 개 오버플로에 있는 **Import groups from CSV**가 **Import Groups from CSV** 모달을 엽니다.

흐름은 이렇습니다. **Download CSV Template**으로 `status-page-groups-template.csv`를 받고, 내용을 채우고, **Choose CSV File**로 고른 다음, 아무것도 기록되기 전에 **Preview Import**로 무엇이 생성될지 확인합니다. 그다음 **Import results** 표가 각 행을 **Created**, **Failed**, **Skipped** 중 하나로 이유와 함께 보여 주므로, 잘못된 행이 소리 없이 사라지지 않습니다.

필수는 `name`뿐입니다. 허용되는 열은 다음과 같습니다.

| 열                   | 설정하는 것                                         |
| ------------------------ | ---------------------------------------------------- |
| `name`                   | 그룹 이름입니다. 필수입니다.                            |
| `parentName`             | 이 그룹이 중첩될 상위 그룹의 이름입니다.         |
| `description`            | 그룹 설명입니다.                                  |
| `isExpandedByDefault`    | 방문자에게 섹션이 펼쳐진 채로 시작할지 여부입니다.        |
| `showCurrentStatus`      | 그룹 제목 옆에 상태를 표시할지 여부입니다.     |
| `showUptimePercent`      | 그룹 옆에 가동 시간 비율을 표시할지 여부입니다. |
| `uptimePercentPrecision` | 그 비율을 소수점 몇 자리로 표시할지입니다.        |
| `viewMode`               | `List` 또는 `Grid`.                                     |
| `rowAxisLabel`           | 그리드 그룹의 행 차원 이름입니다.                     |
| `rowAxisValues`          | 그리드 그룹의 행 값입니다.                        |
| `columnAxisLabel`        | 그리드 그룹의 열 차원 이름입니다.                  |
| `columnAxisValues`       | 그리드 그룹의 열 값입니다.                     |

가져오기는 그룹을 만들 뿐 리소스는 만들지 않습니다 — 모니터는 나중에 **모니터 추가**나 **Add Multiple**로 추가하세요.
