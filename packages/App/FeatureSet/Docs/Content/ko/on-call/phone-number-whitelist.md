# 전화번호 화이트리스트

OneUptime Cloud에서 온콜 SMS와 전화는 아래 번호에서 옵니다. 호출이 차단되거나, 무음 처리되거나, 스팸으로 분류되지 않도록 이 번호들을 휴대폰의 허용 목록에 추가하세요.

## OneUptime Cloud 번호

| 번호 | 국가 |
| --- | --- |
| +13022917020 | 미국(US) |
| +447427817020 | 영국(UK) |

## 휴대폰에서 번호 허용하기

:::steps
1. 두 번호를 휴대폰 연락처에 하나의 연락처로 저장합니다. 예: "OneUptime".
2. 방해 금지 모드, 집중 모드 또는 다른 무음 모드를 사용한다면 그 연락처의 전화와 메시지를 허용합니다.
3. 통화 차단 앱이나 스팸 필터 앱, 또는 통신사의 스팸 차단 기능이 켜져 있다면 그곳에서도 두 번호를 신뢰할 수 있는 번호로 표시합니다.
:::

> [!TIP]
> **사용자 설정** > **알림 방법** 에서 전화번호를 추가하거나 인증하면 이 번호들에서 코드가 오므로, 번호가 잘 도착하는지 빠르게 확인할 수 있습니다.

## 다른 번호에서 호출이 오는 경우

다음과 같은 경우 호출은 위의 번호가 아닌 다른 번호에서 옵니다.

- **프로젝트가 자체 Twilio 계정을 사용하는 경우.** 프로젝트에 프로젝트 기본값으로 설정된 Twilio 구성이 있으면( **프로젝트 설정** > **알림** > **알림 설정** > **Twilio 구성** ) 프로젝트 구성원에게 가는 SMS와 전화는 그 계정을 통해 그 계정의 전화번호에서 발송됩니다. 대신 그 번호들을 화이트리스트에 추가하세요.
- **자체 호스팅 설치를 사용하는 경우.** SMS와 전화는 관리자가 구성한 Twilio 번호에서 옵니다. 프로젝트의 기본 Twilio 구성이거나, **Admin Dashboard** > **설정** > **Call and SMS** 에 있는 설치 전체의 구성입니다. 화이트리스트에 추가할 번호는 관리자에게 문의하세요.
