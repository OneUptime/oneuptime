# Windows 설치

OneUptime 대시보드는 Microsoft Edge 또는 Google Chrome에서 Windows에 앱으로 설치됩니다. 별도의 창에서 열리고, 작업 표시줄과 시작 메뉴에 자체 아이콘이 생기며, 알림을 표시할 수 있습니다. 다운로드할 것은 없습니다. 앱은 사용 중인 OneUptime의 대시보드 그 자체이며, 사용 중인 OneUptime이 최신이면 앱도 항상 최신입니다.

:::cards
- [앱 설치하기](#앱-설치하기): Edge 또는 Chrome에서 몇 번의 클릭으로.
- [고정하고 Windows와 함께 시작하기](#고정하고-windows와-함께-시작하기): 클릭 한 번으로 열 수 있게 둡니다.
- [이 컴퓨터에서 알림 받기](#이-컴퓨터에서-알림-받기): 브라우저를 푸시 알림용으로 등록합니다.
- [문제 해결](#문제-해결): 설치 아이콘이 없음, 알림이 없음, 다시 로그인해야 함.
:::

## 데스크톱 앱의 작동 방식

```mermaid title="대시보드를 설치하면 얻는 것"
flowchart TB
    Browser["Edge 또는 Chrome이<br/>대시보드를 엽니다"]
    Install["앱으로<br/>설치합니다"]
    App["별도의 창에서 열리는<br/>OneUptime,<br/>작업 표시줄과<br/>시작 메뉴에도"]
    OneUptime["사용 중인 OneUptime이<br/>대시보드를 제공합니다"]
    Browser --> Install --> App
    App -->|"열 때마다<br/>대시보드를 불러옴"| OneUptime
```

설치된 앱은 브라우저의 로그인, 설정, 알림 권한을 함께 사용합니다. 브라우저를 닫아도 앱은 자체 창에서 계속 실행됩니다.

## 시작하기 전에

- 최신 Microsoft Edge 또는 Google Chrome이 있는 Windows 10 또는 Windows 11.
- HTTPS로 제공되는 사용 중인 OneUptime의 주소. OneUptime Cloud에서는 `https://oneuptime.com`, 자체 주소라면 `https://oneuptime.example.com` 같은 주소입니다.
- 대시보드에 로그인할 수 있는 계정.

## 앱 설치하기

:::tabs
@tab Edge
1. Edge에서 사용 중인 OneUptime을 열고 로그인합니다.
2. 대시보드의 아무 페이지에서나 주소 표시줄 오른쪽의 설치 아이콘을 클릭한 다음 **설치**를 클릭합니다. 또는 **설정 및 기타 (…) → 기타 도구 → 앱 → 이 사이트를 앱으로 설치**를 엽니다.
3. Edge가 별도의 창에서 OneUptime을 열고, 작업 표시줄이나 시작 메뉴에 고정하도록 제안할 수 있습니다.
@tab Chrome
1. Chrome에서 사용 중인 OneUptime을 열고 로그인합니다.
2. 대시보드의 아무 페이지에서나 주소 표시줄 오른쪽의 설치 아이콘을 클릭한 다음 **설치**를 클릭합니다. 또는 **⋮ → 전송, 저장 및 공유 → 페이지를 앱으로 설치**를 엽니다.
3. Chrome이 별도의 창에서 OneUptime을 열고 시작 메뉴에 추가합니다.
:::

로그인한 뒤 대시보드 페이지에서 설치하세요. 로그인 페이지는 앱이 아닙니다. 나중에 열려면 시작 메뉴에서 OneUptime을 검색합니다.

## 고정하고 Windows와 함께 시작하기

- **작업 표시줄.** 앱이 열려 있을 때 작업 표시줄 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **작업 표시줄에 고정**을 선택합니다.
- **Windows와 함께 시작.** Edge에서 `edge://apps`를 열고 OneUptime의 **세부 정보**를 선택한 다음 **디바이스 로그인 시 자동 시작**을 켭니다. 같은 페이지에서 앱을 작업 표시줄이나 시작 메뉴에 고정하거나 바탕 화면에 바로 가기를 만들 수 있습니다.

## 이 컴퓨터에서 알림 받기

앱은 브라우저를 통해 알림을 표시합니다. 알림을 받으려는 각 프로젝트에서 브라우저를 푸시 알림용으로 등록하세요.

:::steps
### 푸시 디바이스 열기
앱에서 **사용자 설정 → 알림 방법**을 열고 **Push Notifications** 탭을 엽니다.

### 이 브라우저 등록하기
**디바이스 등록**을 클릭하고, **디바이스 이름**은 `Edge on Windows` 같은 제안된 이름을 그대로 두거나 바꾼 다음, **디바이스 등록**을 다시 클릭합니다. OneUptime이 알림을 표시해도 되는지 브라우저가 물으면 **허용**을 선택합니다.

### 테스트 보내기
**Browser Registered** 대화 상자에서 **Send Test Notification**을 클릭합니다. 아무것도 나타나지 않으면 Windows 자체의 알림 설정을 확인하세요. [문제 해결](#문제-해결)을 참고하세요.
:::

브라우저는 Windows가 허용하는 것보다 크게 울릴 수 없으며, 방해 금지 모드를 무시할 수 없습니다. 반드시 깨워야 하는 호출에는 중요 알림을 켠 모바일 앱을 사용하세요. [Android 설치](/docs/mobile-desktop-apps/android-installation#무음-모드에서도-울리게-하기) 또는 [iOS 설치](/docs/mobile-desktop-apps/ios-installation#무음-모드에서도-울리게-하기)를 참고하세요.

자체 호스팅 OneUptime에서는 브라우저 알림에 서버의 VAPID 키가 필요합니다. [푸시 알림](/docs/self-hosted/push-notifications#자체-호스팅-설정)을 참고하세요.

## 업데이트

업데이트할 것이 없습니다. 앱은 열 때마다 사용 중인 OneUptime에서 대시보드를 불러오므로, 사용 중인 OneUptime이 업그레이드되면 함께 바뀝니다. 업그레이드 이전부터 열려 있던 창은 Ctrl+R로 새로 고치세요.

## 제거

:::tabs
@tab Edge
`edge://apps`를 열고 OneUptime의 **세부 정보**를 선택한 다음 **제거**를 선택합니다.
@tab Chrome
앱 창에서 **⋮** 메뉴를 열고 앱을 제거하는 항목을 선택한 다음 **삭제**를 선택합니다.
:::

Windows의 **설정 → 앱 → 설치된 앱**에도 앱이 표시되며, 그곳에서 **제거**를 눌러도 제거됩니다.

앱을 제거해도 브라우저의 등록은 해제되지 않습니다. 브라우저는 계속 알림을 받습니다. 알림을 멈추려면 **사용자 설정 → 알림 방법**의 **Push Notifications** 탭에서 **삭제**로 브라우저를 삭제하세요.

## 문제 해결

:::details 주소 표시줄에 설치 아이콘이 없음
로그인 페이지가 아니라 로그인한 뒤의 대시보드 페이지를 열고, 주소가 `https://`로 시작하는지 확인하세요. 브라우저는 안전한 사이트에서만 앱을 설치합니다. 그래도 아이콘이 보이지 않으면 위에서 설명한 대로 브라우저 메뉴를 사용하세요. 다른 브라우저는 사이트를 앱으로 설치하지 못할 수 있으니 Edge나 Chrome을 사용하세요.
:::

:::details 알림이 나타나지 않음
- **사용자 설정 → 알림 방법**의 **Push Notifications** 탭에서 이 브라우저가 목록에 있는지 확인하고 **테스트 알림**을 보냅니다.
- Windows에서 **설정 → 시스템 → 알림**을 엽니다. 알림이 켜져 있고 브라우저에 대해서도 켜져 있어야 하며, 방해 금지 모드는 꺼져 있어야 합니다. Windows 10에서는 이 페이지의 이름이 “알림 및 작업”입니다.
- 브라우저가 OneUptime의 알림을 차단하고 있다면 주소 표시줄 왼쪽의 아이콘을 클릭해 사이트의 알림을 허용하고 브라우저를 다시 등록합니다.
- 자체 호스팅 OneUptime에서는 서버에 VAPID 키가 없으면 **디바이스 등록** 대화 상자에 그렇게 표시됩니다.
:::

:::details 앱이 다시 로그인하라고 함
앱은 브라우저의 로그인을 함께 사용합니다. 브라우저에서 로그아웃하거나 쿠키를 지우면 앱에서도 로그아웃됩니다.
:::
