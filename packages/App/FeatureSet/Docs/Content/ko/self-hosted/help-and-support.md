# 도움말 및 지원

OneUptime이 제공하는 도움을 자체 팀으로 연결합니다. 사람들이 보는 지원 주소, 채팅, 도움말 페이지, **피드백 보내기**가 전달되는 곳, 초대가 필요한 사람에게 싱글 사인온이 표시하는 내용, 모바일 앱을 받으라는 안내가 대상입니다. 각각 OneUptime의 기본값을 유지하거나, 직접 지정한 주소나 링크를 가리키게 하거나, 숨길 수 있습니다.

:::cards
- [도움이 연결되는 곳 변경하기](#도움이-연결되는-곳-변경하기): Admin Dashboard의 페이지 하나.
- [각 설정이 바꾸는 것](#각-설정이-바꾸는-것): 모든 위치와 그 기본값, 선택지.
- [피드백 보내기](#피드백-보내기): 사람들이 쓴 내용이 전송되는 곳.
- [로그인 메시지](#로그인-메시지): 초대를 누구에게 요청해야 하는지.
- [구성에서 설정하기](#구성에서-설정하기): Helm 값 또는 `config.env`, 새 서버용.
:::

## 도움이 연결되는 곳 변경하기

:::steps
### 도움말 및 지원 열기
Admin Dashboard에서 **설정**을 열고 사이드 메뉴의 **도움말 및 지원**을 엽니다.

### 위치 변경하기
옆에 있는 **변경**을 선택하고 **기본값**, 직접 지정한 주소나 링크, 또는 **숨기기**를 고른 다음 **저장**을 선택합니다. **데모 요청**과 **버그 신고 또는 기능 요청**은 스위치이며, 전환하는 즉시 저장됩니다.

### 사람들에게 보이는 내용 확인하기
도움말 메뉴와 로그인 화면은 각 설정 옆에 미리 보기로 표시됩니다. 사람들은 다음에 페이지를 열 때 변경 내용을 봅니다.
:::

위치를 변경하기 전까지는 OneUptime이 늘 보여 주던 내용이 표시되므로, 이 페이지를 한 번도 열지 않은 서버는 이전과 똑같아 보입니다.

## 각 설정이 바꾸는 것

| 설정 | 사람들이 보는 곳 | 기본값 | 직접 설정 |
| --- | --- | --- | --- |
| **지원 이메일** | 도움말 › **지원 이메일**, "페이지를 찾을 수 없습니다" 화면의 **지원팀에 문의**, 계정 이메일, 오류 화면에서 지원 번들을 보내도록 안내하는 주소 | `support@oneuptime.com` | 이메일 주소 |
| **채팅** | 도움말 › **Slack에서 채팅**, API 참조 상단의 채팅 링크 | Slack의 OneUptime 커뮤니티 | 링크. Slack 또는 Microsoft Teams 링크는 이름이 그대로 유지되고, 그 밖의 링크는 **지원팀과 채팅**으로 표시됩니다 |
| **데모 요청** | 도움말 › **데모 요청** | 표시됨 | 숨기기만 가능 |
| **피드백 보내기** | 도움말 › **피드백 보내기**, 검색의 **피드백 보내기** | 이 서버의 관리자 | 이메일 주소 또는 직접 지정한 페이지 |
| **도움말 및 지원** | 바닥글의 **도움말 및 지원**, 로그인 페이지의 **연락처**, API 참조 상단의 **지원** | `https://oneuptime.com/support` | 링크 |
| **버그 신고 또는 기능 요청** | 제품 메뉴 하단, 피드백 후에 제안되는 공개 GitHub 이슈, 문서와 API 참조의 GitHub 링크 | 표시됨 | 숨기기만 가능 |
| **모바일 앱 받기** | **나에게 연락하는 방법**, 온콜 설정, 홈에서 새 구성원의 첫 단계, **프로젝트 설정**의 **모바일 앱** | App Store 및 Google Play | 직접 지정한 페이지(예: 기기 관리 도구의 회사 포털) |
| **초대가 필요한 사람을 위한 메시지** | "You need to be invited." 및 "No project access."라고 표시하는 싱글 사인온 화면 | OneUptime의 문장 | 직접 작성한 문구 |

메시지를 제외한 모든 설정은 숨길 수도 있습니다. 링크는 `https://`, `http://` 또는 `mailto:`로 시작합니다. `javascript:`를 비롯한 다른 종류의 링크는 페이지에서 거부되고, 서버에서도 다시 거부됩니다.

Admin Dashboard 자체의 도움말 메뉴, 바닥글, 제품 메뉴는 OneUptime의 링크를 유지합니다. 이 메뉴들은 서버에 대한 도움을 OneUptime에서 받는 이 서버의 관리자를 위한 것이기 때문입니다.

### 계정 이메일

자체 호스팅 서버에서는 초대나 이메일 주소 변경 같은 계정 이메일이 마지막에 OneUptime 지원팀이 아니라 이 서버의 관리자를 안내합니다. 직접 지정한 지원 주소가 있으면 이메일은 그 주소를 링크로 알려 줍니다. "도움이 필요하신가요? it-help@example.com(으)로 문의하세요." 기본값이거나 숨긴 경우에는 지금까지와 같은 문구입니다.

### 문서와 API 참조

이 서버가 제공하는 문서와 API 참조도 같은 설정을 따릅니다. **버그 신고 또는 기능 요청**을 숨기면 어떤 페이지도 GitHub로 연결되지 않으며, **이 페이지가 도움이 되었나요?**는 답변이 보관되거나 전송되는 곳에서만 묻습니다. API 참조의 상단 바에는 선택한 채팅과 도움말 페이지가 표시되고, 숨긴 경우에는 둘 다 표시되지 않습니다.

### 링크를 읽을 수 있는 사람

지원 주소와 **도움말 및 지원** 링크는 로그인 페이지에도 표시되므로, 그 페이지를 열 수 있는 사람은 누구나 읽을 수 있습니다. 채팅 링크와 모바일 앱 페이지는 로그인한 사람에게만 전송됩니다. 채팅 링크는 워크스페이스로의 초대인 경우가 많기 때문입니다. 같은 이유로, 누구나 읽을 수 있는 문서와 API 참조는 직접 지정한 채팅 링크를 이 서버에 로그인한 사람에게만 보여 줍니다.

## 피드백 보내기

| 선택지 | 동작 |
| --- | --- |
| **기본값** | 지금까지와 같습니다. **설정** › **이메일**에서 지정한 **관리자 알림 이메일**로 이메일이 전송되며, 지정되지 않았으면 **피드백**에 이 서버의 관리자를 위해 보관됩니다. OneUptime Cloud에서는 OneUptime 팀으로 전송됩니다. |
| **이메일 주소** | 이 서버의 이메일 설정을 통해 보낸 사람의 이름과 이메일 주소와 함께 그 주소로 이메일이 전송되므로 팀에서 회신할 수 있습니다. 보낸 사람은 사본을 받습니다. |
| **직접 지정한 페이지** | **피드백 보내기**를 누르면 헬프데스크 양식 같은 페이지가 새 탭에서 열립니다. OneUptime에서는 아무것도 전송되지 않습니다. |
| **"피드백 보내기" 숨기기** | **피드백 보내기**가 어디에도 제공되지 않습니다. |

서버가 이메일을 보낼 수 없는 동안에는 이메일 주소를 선택하면 팀에 도달할 수 없는 메시지를 받는 대신 **피드백 보내기**가 숨겨지며, 설정 페이지에도 그렇게 표시됩니다. **설정** › **이메일**에서 이메일을 설정하면 **피드백 보내기**가 자동으로 다시 나타납니다.

안내형 설정이 얼마나 쉬웠는지처럼 OneUptime이 묻는 질문은 **피드백 보내기**가 아닙니다. 그 답변은 **피드백**에 남으며, 거기서 **어땠는지 묻기**로 질문을 끌 수 있습니다.

## 로그인 메시지

서버 자체의 싱글 사인온은 두 종류의 사람을 돌려보냅니다. 공급자가 계정을 만들지 않는 상태에서 계정이 없는 사람("You need to be invited.")과, 계정이 어떤 프로젝트에도 속하지 않은 사람("No project access.")입니다. 둘 다 초대가 필요하므로 두 화면 모두 누구에게 요청하고 어떻게 연락하면 되는지를 담은 메시지를 표시합니다.

```text
Ask the IT service desk to invite you to OneUptime:
it-help@example.com or https://help.example.com/oneuptime
```

- 메시지는 최대 1000자의 일반 텍스트이며 `<` 또는 `>` 기호를 포함할 수 없습니다.
- 각 줄은 하나의 문단이 되고, 그 안의 링크와 이메일 주소는 링크가 됩니다.
- 화면 제목은 그대로 유지되며, 모바일 앱에도 같은 문구가 표시됩니다.

## 모바일 앱 안내

직접 지정한 페이지가 있으면 모바일 앱을 받으라는 모든 안내가 그 페이지를 가리킵니다. 페이지의 QR 코드 하나가 그 주소를 이름으로 하여 표시되고, 단계에는 앱이 연결할 이 서버의 주소가 계속 표시됩니다. 숨기면 안내가 전혀 없습니다.

- **모바일 앱 받기**는 홈에서 새 구성원의 첫 단계에서 빠집니다. 첫 단계는 그 사람에게 연락할 수 있고 테스트 호출이 도달하면 여전히 완료됩니다.
- **나에게 연락하는 방법**과 온콜 설정은 브라우저만 제공합니다.
- **모바일 앱**은 **프로젝트 설정**에서 빠집니다.
- 안내형 설정, 홈, 팀의 규정 준수 규칙, AI에게 질문 등 OneUptime이 연락 방법을 나열하는 곳에서는 더 이상 그 가운데 앱을 언급하지 않습니다.

## 구성에서 설정하기

Helm이나 Docker Compose로 설치한 서버는 이 설정을 미리 지정한 채로 시작할 수 있습니다. Helm 차트의 `helpAndSupport` 값에서, 또는 Docker Compose의 경우 `config.env`에서 지정합니다.

```yaml
helpAndSupport:
  supportEmail: it-help@example.com
  chat: https://example.slack.com/archives/C024BE91L
  requestDemo: hidden
  gitHub: hidden
  inviteMessage: |
    Ask the IT service desk to invite you to OneUptime:
    it-help@example.com
```

| Helm 값 | `config.env` | 받는 값 |
| --- | --- | --- |
| `supportEmail` | `HELP_AND_SUPPORT_SUPPORT_EMAIL` | 이메일 주소 또는 `hidden` |
| `chat` | `HELP_AND_SUPPORT_CHAT` | 링크 또는 `hidden` |
| `requestDemo` | `HELP_AND_SUPPORT_REQUEST_DEMO` | `shown` 또는 `hidden` |
| `giveFeedback` | `HELP_AND_SUPPORT_GIVE_FEEDBACK` | 이메일 주소, 링크 또는 `hidden` |
| `helpLink` | `HELP_AND_SUPPORT_HELP_LINK` | 링크 또는 `hidden` |
| `gitHub` | `HELP_AND_SUPPORT_GITHUB` | `shown` 또는 `hidden` |
| `mobileApp` | `HELP_AND_SUPPORT_MOBILE_APP` | 링크 또는 `hidden` |
| `inviteMessage` | `HELP_AND_SUPPORT_INVITE_MESSAGE` | 일반 텍스트 |

- 이 값은 서버가 시작될 때, **도움말 및 지원**에 아무것도 저장되지 않은 동안에만 읽힙니다. 그 뒤로는 페이지가 설정을 보관합니다. 페이지에서 한 변경은 유지되며, 다시 시작해도 되돌아가지 않습니다.
- 나중에 구성에서 바꾼 값은 적용되지 않으며, 서버 로그에 그 사실이 기록됩니다. 페이지에서 바꾸세요.
- 각 값은 페이지와 같은 방식으로 검사됩니다. `javascript:` 링크처럼 거부될 값은 빠지며, 페이지와 서버 로그에 그 이유가 표시됩니다. 나머지 값은 그대로 설정됩니다.
- OneUptime 기본값을 유지하려면 값을 비워 두세요. 두 스위치에는 `true`와 `false`도 쓸 수 있습니다.
- 페이지는 구성에서 온 각 설정을 직접 바꿀 때까지 표시해 둡니다.
