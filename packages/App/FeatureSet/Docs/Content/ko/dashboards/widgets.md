# 위젯

위젯은 대시보드의 한 타일입니다. 이 페이지는 추가할 수 있는 모든 위젯, 각 위젯이 보여주는 내용, 그리고 어떤 상황에서 사용할지 정리한 카탈로그입니다.

위젯을 캔버스에서 끌어다 놓는 방법은 [대시보드 작성하기](/docs/dashboards/authoring)를 참조하시기 바랍니다.

## 차트와 숫자

### Chart

대시보드의 시간 범위에 걸쳐 하나 이상의 메트릭 시리즈를 선, 막대, 또는 영역 차트로 표시합니다.

**설정**:

- 하나 이상의 메트릭 쿼리.
- 두 쿼리를 결합하는 선택적 공식(예: 오류율을 얻기 위한 `errors / total * 100`).
- 리셋 없이 증가하는 누적 카운터를 위한 "show as rate" 옵션.
- 표시 옵션: 누적 또는 겹침, Y축 단위, 범례 위치, 차트 유형.

용도: 추세가 중요한 경우. 시간 경과에 따른 지연, 오류 수, 큐 깊이 등 선의 형태가 이야기를 전달하는 경우에 사용합니다.

### Value

선택적인 색상 임계값이 있는 단일 큰 숫자입니다.

**설정**:

- 하나의 숫자를 반환하는 메트릭 쿼리(마지막 값, 평균, 또는 시간 범위 내 최대값).
- 선택적인 **경고** 임계값(이상에서 노란색).
- 선택적인 **심각** 임계값(이상에서 빨간색).
- 숫자 형식과 단위.

용도: 하나의 숫자가 질문에 답할 때. 현재 오류율, 지금 P95 지연, 열린 인시던트 수 등.

### Gauge

최솟값, 최댓값, 경고 구간, 심각 구간이 있는 원형 게이지입니다.

**설정**: 메트릭 쿼리와 네 가지 경계.

용도: 값이 알려진 범위 안에 들어가는 경우. CPU 백분율(0~100%), 디스크 사용량, 큐 용량 등에 사용합니다.

### Table

메트릭 결과를 그룹당 한 행씩 표시하는 테이블입니다.

**설정**: 메트릭 쿼리(보통 호스트나 서비스 같은 라벨로 그룹화), 표시할 열, 행 제한.

용도: 추세 대신 분석을 원할 때. 가장 시끄러운 호스트 10개, 서비스당 오류 수, 엔드포인트당 요청 수 등에 사용합니다.

## Text

정적인 Markdown 블록입니다.

**설정**: Markdown 본문. 제목, 목록, 링크, 강조, 코드 블록이 모두 렌더링됩니다.

용도: 섹션 제목, 컨텍스트 단락, 런북 링크 목록, 또는 인시던트 중 임시 배너 등에 사용합니다.

## HTML

직접 작성한 HTML, CSS, JavaScript를 위젯으로 렌더링합니다.

**설정**: HTML 본문, 선택적 스타일시트, 선택적 스크립트, 그리고 세 가지 권한 토글.

용도: 기본 제공 위젯으로는 다룰 수 없는 것이 필요할 때. 삽입한 서드파티 배지, 내부 API에서 가져온 테이블, 커스텀 범례, 자체 도구로 연결되는 스타일이 적용된 링크 모음 등에 사용합니다.

### 할 수 있는 것과 할 수 없는 것

위젯은 자체 격리 출처(isolated origin)의 샌드박스 프레임 안에서 렌더링됩니다. 그 프레임 안에서 여러분의 코드는 사실상 무엇이든 할 수 있습니다. DOM 구성, 타이머 실행, 임의의 URL에서 데이터 가져오기, 캔버스에 그리기 등이 가능합니다.

할 수 없는 것은 위젯을 둘러싼 OneUptime 페이지에 접근하는 일입니다. 대시보드의 DOM, 쿠키, 로컬 스토리지, API 세션에 접근할 수 없으며, 브라우저 탭을 다른 곳으로 이동시킬 수도 없습니다. 이는 대시보드가 비공개이든 공개로 공유되든 동일하게 적용됩니다.

무언가를 붙여넣기 전에 알아 둘 만한 두 가지 결과는 다음과 같습니다.

- 위젯에서 보내는 `fetch`는 불투명한 출처(opaque origin)에서 나가는 교차 출처 요청이므로, 호출 대상 서버가 CORS로 이를 허용해야 합니다. 여기에서 OneUptime API를 호출하는 것은 지원되지 않습니다.
- 위젯은 투명한 상태로 시작합니다. 카드를 가득 채우려면 CSS에서 `body`에 배경을 지정하시기 바랍니다.

### 대시보드 변수 사용하기

HTML, CSS, JavaScript 어디에든 `{{variableName}}`을 쓰면 위젯이 렌더링되기 전에 해당 변수의 현재 값으로 치환됩니다. 새 값을 선택하면 위젯이 다시 렌더링됩니다. 존재하지 않는 변수를 가리키는 자리 표시자는 그대로 남습니다.

스크립트는 `window.ONEUPTIME`에서 동일한 값과 함께 대시보드의 시간 범위도 받습니다.

```javascript
window.ONEUPTIME.variables.environment; // 현재 값, 설정되지 않았다면 ""
window.ONEUPTIME.startDate; // ISO 8601 문자열, 대시보드 시간 범위의 시작
window.ONEUPTIME.endDate; // ISO 8601 문자열, 그 끝
```

대시보드가 새로고침될 때마다 위젯도 다시 로드되므로, 자체적으로 데이터를 가져오는 위젯도 새로고침 간격에 맞춰 갱신됩니다.

### 권한

**Run JavaScript**(JavaScript 실행, 기본값 켜짐)은 스크립트를 실행합니다. 끄면 마크업과 스타일만 렌더링되며, 스크립트는 단순히 차단되는 것이 아니라 위젯에서 아예 제외됩니다.

**Open links in a new tab**(링크를 새 탭에서 열기, 기본값 켜짐)은 링크와 `window.open`이 브라우저 탭을 열 수 있게 합니다. 링크는 항상 새 탭에서 열리며, 위젯이 대시보드 자체를 다른 곳으로 이동시킬 수는 없습니다.

**Allow forms to submit**(form 제출 허용, 기본값 꺼짐)은 위젯 안의 `<form>`이 제출될 수 있게 합니다.

대시보드를 편집할 수 있는 사람이 이 위젯이 무엇을 실행할지 결정하고, 대시보드를 보는 모든 사람이 그것을 실행하게 됩니다. 공개 대시보드에서는 익명 방문자도 여기에 포함됩니다. HTML 위젯이 있는 대시보드의 편집 권한은 여러분이 배포하는 다른 코드에 대한 접근 권한과 똑같이 다루시기 바랍니다.

## 로그와 트레이스

### Log Chart

대시보드의 시간 범위에 걸친 로그 볼륨의 시계열 차트입니다. 각 계열이 심각도를 나타내므로 오류 급증이 일반 트래픽과 구분되어 드러납니다.

**설정**:

- 막대, 선, 영역 차트 시각화. 막대와 영역 차트는 심각도 계열을 누적해서 보여 줍니다.
- 선택적 심각도 필터.
- 선택적 로그 본문 텍스트 검색.
- 검색 가능한 키/값 행을 사용한 OpenTelemetry 속성 정확 일치 필터. 입력하는 동안 속성 이름과 알려진 값이 제안되며, 사용자 지정 값도 계속 지원됩니다.
- 선택적 제목.

대시보드의 시간 범위 및 새로 고침 컨트롤이 차트를 자동으로 다시 조회합니다. 대시보드의 텔레메트리 속성 변수도 다중 선택 변수를 포함해 이 위젯에 적용됩니다.

Log Chart는 현재 인증된 대시보드가 필요합니다. 공개 대시보드는 프로젝트의 로그 집계를 익명으로 노출하는 대신 위젯을 사용할 수 없음으로 표시합니다.

용도: 대시보드를 벗어나지 않고 로그 볼륨의 변화를 포착하거나, 오류·경고·정보 로그를 비교하고자 할 때.

### Log Stream

필터와 일치하는 로그 줄의 실시간 테일입니다.

**설정**: 로그 필터(서비스, 심각도, 속성)와 표시할 열.

용도: 대시보드를 벗어나지 않고 애플리케이션이 지금 무엇을 말하고 있는지 보고 싶을 때.

### Trace List

필터와 일치하는 최근 트레이스 목록입니다. 소요 시간, 상태, 서비스가 표시됩니다.

**설정**: 트레이스 필터(서비스, 상태, 속성).

용도: 차트 대신 최근 활동 목록을 원할 때. 일반적인 패턴은 상단에 지연 차트를 두고 아래에 느린 트레이스 목록을 두는 것입니다.

## 실시간 목록

### Incident List

필터와 일치하는 인시던트의 실시간 목록입니다.

**설정**: 상태, 심각도, 라벨, 모니터 또는 팀별 필터.

용도: 대시보드가 "지금 무엇이 망가졌나?"에 답할 때.

### Alert List

필터와 일치하는 알림의 실시간 목록입니다.

**설정**: 상태, 심각도, 라벨별 필터.

용도: 팀 대시보드가 해당 서비스의 알림을 추적할 때.

### Monitor List

모니터와 현재 상태의 실시간 목록입니다.

**설정**: 모니터 유형, 라벨, 또는 현재 상태별 필터.

용도: "모든 사이트가 정상인가?" 같은 전체 보기를 원할 때.

## 서비스 수준 목표

### SLO

하나의 서비스 수준 목표를 단일 숫자 또는 시간에 따른 선으로 그립니다.

**설정**: 어떤 SLO인지, 그 세 가지 숫자 중 무엇을 보여줄지(SLI, Error Budget Remaining, Burn Rate), Tile 또는 Chart 표시, 그리고 선택적 제목.

- **Tile** 은 현재 숫자를 보여 주고, 두 번째 줄이 있는 경우 함께 표시합니다. SLI 아래에는 목표치가, 오류 예산 아래에는 남은 시간(분)이 표시됩니다. 상태 표시 알약이 전체 색을 결정합니다.
- **Chart** 는 같은 숫자를 대시보드의 시간 범위에 걸쳐 그리며, SLI 계열에는 목표치를 점선으로 표시합니다. 이력은 평가 워커가 몇 분마다 기록하므로, 방금 만든 SLO는 첫 평가가 끝날 때까지 빈 차트로 나타납니다.

용도: 대시보드가 "지금 무슨 일이 일어나고 있는가"보다 "약속한 수준을 지키고 있는가"에 답할 때.

SLO 위젯은 [공개 대시보드](/docs/dashboards/sharing)에서 동작합니다. 공개되는 것은 SLO의 핵심 숫자, 즉 이름, 목표치, 현재 SLI, 남은 오류 예산, 번 레이트, 상태이며, 위젯이 그중 무엇을 그리는지와는 무관합니다. 정의는 비공개로 유지됩니다. 감시하는 모니터, 라벨, 설명, 쿼리, 평가 일정은 공개 방문자에게 전송되지 않습니다. Tile 위젯은 그 현재 숫자만 공개하고, Chart 위젯은 자신이 그리는 한 계열의 이력까지만 추가로 공개합니다.

## Kubernetes 리소스 목록

[Kubernetes 에이전트](/docs/monitor/kubernetes-agent)가 설치된 프로젝트용입니다. 각각 클러스터, 네임스페이스, 라벨에 대한 선택적 필터를 받습니다.

- **Kubernetes Pod List** — 단계, 재시작, 노드와 함께 파드를 표시합니다.
- **Kubernetes Node List** — 조건과 용량과 함께 노드를 표시합니다.
- **Kubernetes Namespace List** — 네임스페이스와 워크로드 수.
- **Kubernetes Deployment List** — 원하는 레플리카와 준비된 레플리카가 있는 배포.
- **Kubernetes StatefulSet List** — 준비된 레플리카가 있는 스테이트풀 셋.
- **Kubernetes DaemonSet List** — 원하는 것과 준비된 것이 있는 데몬 셋.
- **Kubernetes Job List** — 작업과 완료 상태.
- **Kubernetes CronJob List** — 스케줄과 마지막 실행이 있는 cron 작업.

용도: 해당 워크로드의 텔레메트리와 Kubernetes 상태를 함께 보여주는 단일 대시보드를 원할 때.

## Docker 리소스 목록

Docker 모니터링이 설정된 프로젝트용입니다.

- **Docker Host List** — Docker를 실행하는 호스트와 컨테이너 수.
- **Docker Container List** — 상태, 이미지, 호스트, 가동 시간이 있는 컨테이너.
- **Docker Image List** — 이미지와 크기.
- **Docker Network List** — Docker 네트워크와 연결된 컨테이너.
- **Docker Volume List** — Docker 볼륨과 사용량.

## 인프라

### Host List

OneUptime의 서버 모니터가 모니터링하는 호스트를 상태, CPU, 메모리, 가동 시간과 함께 표시합니다.

**설정**: 라벨이나 현재 상태별 필터.

## 네트워크

### Network Map

네트워크 사이트를 세계 지도 위에 그리며, 각 사이트를 자체 위도와 경도에 고정하고 그 사이트로 집계된 모니터 상태에 따라 색을 입힙니다. 서로 가까운 사이트는 개수가 안에 표시된 하나의 마커를 공유하고, 정확히 한 사이트를 나타내는 마커는 클릭하면 그 사이트를 엽니다.

지도는 그려 낸 사이트에 맞춰 스스로 범위를 잡습니다. 한 국가 안에 있는 자산이면 그 국가로 화면이 채워지고, 여러 대륙에 퍼져 있으면 세계 전체로 열립니다. 확대나 이동 컨트롤은 없습니다. 대시보드 타일은 한 장의 그림이고, 계층을 따라 들어가는 곳은 Network 아래의 Network Map 페이지입니다.

지도 위에는 다운된 사이트가 몇 개인지 표시됩니다. 초록 점 200개 사이의 2픽셀짜리 빨간 점은 대시보드를 보는 거리에서 아무도 읽어 내지 못하기 때문입니다. 그 아래의 커버리지 줄은 지도가 무엇을 보여 주지 _않는지_ 알려 줍니다. 좌표가 없는 사이트, 그리고 행 상한에 도달했는지 여부입니다.

**설정**: 제목, 지도 또는 목록 보기, 그릴 사이트 최대 개수, 사이트 이름 표시 여부, 사이트 유형과 상태별 필터. 지도가 너무 붐벼서 읽기 어려워지면 사이트 이름은 자동으로 사라지며, 툴팁은 여전히 모든 마커의 이름을 알려 줍니다.

사이트는 좌표가 있을 때만 나타납니다. 고정하려면 사이트에 위도와 경도를 추가하시기 바랍니다(CSV에서 가져올 수도 있습니다).

## 어떤 위젯을 사용해야 할까요?

몇 가지 간단한 규칙은 다음과 같습니다.

- **시간 경과에 따른 추세?** Chart.
- **시간 경과에 따른 로그 볼륨이나 오류 급증?** Log Chart.
- **지금 중요한 하나의 숫자?** Value(명확한 최솟값/최댓값이 있다면 Gauge).
- **여러 항목에 걸친 분석?** Table.
- **지금 시스템에서 무슨 일이 벌어지고 있는지?** Log Stream, Trace List, Incident List.
- **특정 리소스 그룹의 상태?** 일치하는 목록 위젯.
- **약속한 신뢰성을 지키고 있는가?** SLO.
- **네트워크가 세계 어디에 있고 무엇이 빨간지?** Network Map.
- **제목, 단락, 또는 링크?** Text.
- **위의 어느 것으로도 다룰 수 없는 것?** HTML — 단, 기본 제공 위젯으로 정말 안 되는지 확인한 뒤에만 사용하시기 바랍니다.

대부분의 대시보드는 몇 가지를 섞어 사용합니다. 상단에 차트, 옆에 값 한두 개, 텍스트 구분자, 그리고 아래에 목록 한두 개 같은 식으로 구성할 수 있습니다.
