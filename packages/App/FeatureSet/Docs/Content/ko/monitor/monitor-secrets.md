# 모니터 시크릿

모니터링 확인에 사용하려는 민감한 정보를 저장하기 위해 시크릿을 사용할 수 있습니다. 시크릿은 암호화되어 안전하게 저장됩니다.

### 시크릿 추가

시크릿을 추가하려면 OneUptime 대시보드 -> 모니터 -> 설정 -> 시크릿 -> 모니터 시크릿 생성으로 이동하십시오.

![시크릿 생성](/docs/static/images/CreateMonitorSecret.png)

시크릿의 이름과 값을 입력한 다음 **접근** 단계에서 시크릿을 사용할 수 있는 모니터를 선택합니다. 이 예에서는 `ApiKey` 시크릿을 추가했습니다.

**참고**: 시크릿은 암호화되어 안전하게 저장됩니다. 저장한 후에는 시크릿 값이 다시 표시되지 않습니다 — 목록에서도, 편집 양식에서도, API를 통해서도 마찬가지입니다. 값을 잃어버린 경우 원래 출처에서 다시 가져와 설정해야 합니다. 시크릿을 교체하려면 해당 행의 **시크릿 값 업데이트** 버튼을 사용하세요. 삭제 후 다시 만들 필요는 없습니다.

### 시크릿을 사용할 수 있는 모니터 선택

각 시크릿에는 다음 세 가지 접근 옵션 중 하나가 있습니다.

- **모든 모니터**: 프로젝트의 모든 모니터가 시크릿을 사용할 수 있으며, 나중에 만드는 모니터도 포함됩니다. 여러 모니터가 함께 쓰는 자격 증명에 사용하세요.
- **특정 모니터**: 선택한 모니터만 시크릿을 사용할 수 있습니다. 기본 옵션이며, 이 옵션들이 생기기 전에 만든 시크릿도 이렇게 동작합니다.
- **레이블이 있는 모니터**: 선택한 레이블 중 하나 이상이 있는 모니터가 시크릿을 사용할 수 있습니다. 모니터에 해당 레이블 중 하나를 추가하면 접근 권한이 생기고, 레이블을 제거하면 다음 실행부터 접근 권한이 없어집니다.

시크릿 행의 **편집**으로 언제든지 옵션을 바꿀 수 있습니다. 선택한 옵션의 목록만 유지됩니다. **모든 모니터**로 바꾸면 시크릿의 모니터 목록과 레이블 목록이 비워지고, **특정 모니터**와 **레이블이 있는 모니터** 사이를 전환하면 이전에 쓰던 목록이 비워집니다.

시크릿은 다른 프로젝트의 모니터에서는 절대 사용할 수 없습니다.

시크릿을 사용할 수 있는 모니터를 편집할 수 있는 사람은 모니터가 연결하는 모든 대상으로 그 시크릿을 보낼 수 있습니다. **모든 모니터**의 경우 프로젝트에서 모니터를 만들거나 편집할 수 있는 모든 사람이 해당됩니다. **레이블이 있는 모니터**의 경우 모니터에 해당 레이블 중 하나를 추가할 수 있는 사람도 포함됩니다.

API에서는 접근 옵션이 `monitorAccess` 필드입니다: `All Monitors`, `Specific Monitors` 또는 `Monitors With Labels`. `monitors` 및 `labels` 필드에 목록이 들어갑니다. `monitorAccess` 없이 만든 시크릿은 `Specific Monitors`가 됩니다.

### 시크릿 사용

다음 모니터링 유형에서 시크릿을 사용할 수 있습니다:

- API (요청 헤더, 요청 본문 및 URL에서)
- 웹사이트, IP, 포트, Ping, SSL 인증서 (URL에서)
- 합성 모니터, 커스텀 코드 모니터 (코드에서)
- SNMP 모니터 (커뮤니티 문자열, SNMPv3 인증 키 및 개인 키에서)

![시크릿 사용](/docs/static/images/UsingMonitorSecret.png)

시크릿을 사용하려면 시크릿을 사용하려는 필드에 `{{monitorSecrets.SECRET_NAME}}`을 추가합니다. 예를 들어, 이 경우 요청 헤더 필드에 `{{monitorSecrets.ApiKey}}`를 추가했습니다.

시크릿은 합성 또는 커스텀 코드 모니터 스크립트가 실행되기 전에 프로브에 주입되므로 실행 중인 스크립트 내에서 `{{monitorSecrets.ApiKey}}`와 같은 참조가 복호화된 값으로 확인됩니다.

모니터가 사용할 수 없는 시크릿을 참조하면 참조는 그대로 남고 값으로 바뀌지 않습니다.

모니터를 저장하기 전에 테스트하면 **모든 모니터**에서 사용할 수 있는 시크릿만 채워집니다. 새 모니터는 어떤 목록에도 없고 아직 레이블도 없기 때문입니다. 모니터를 저장한 후에는 테스트에서 그 모니터가 사용할 수 있는 모든 시크릿을 사용합니다.
