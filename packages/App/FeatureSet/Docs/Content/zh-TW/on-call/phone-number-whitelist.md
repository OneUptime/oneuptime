# 電話號碼白名單

在 OneUptime Cloud 上，待命簡訊和電話來自下列號碼。請將它們加入手機的允許清單，以免呼叫被封鎖、靜音或被標記為垃圾來電。

## OneUptime Cloud 號碼

| 號碼 | 國家/地區 |
| --- | --- |
| +13022917020 | 美國（US） |
| +447427817020 | 英國（UK） |

## 在手機上允許這些號碼

:::steps
1. 將兩個號碼當作同一個聯絡人儲存到手機的聯絡資訊中，例如「OneUptime」。
2. 如果您使用勿擾模式、專注模式或其他靜音模式，請允許該聯絡人的來電和訊息。
3. 如果開啟了來電過濾或垃圾訊息過濾 App，或電信業者的垃圾來電防護，請在那裡也將兩個號碼標記為信任。
:::

> [!TIP]
> 在 **使用者設定** > **通知方式** 中新增或驗證電話號碼時，會從這些號碼傳送驗證碼給您，因此這是確認它們能否送達的快速方法。

## 呼叫來自其他號碼時

在以下情況下，您的呼叫會來自上述以外的號碼：

- **您的專案使用自己的 Twilio 帳戶。** 當專案有一個設為專案預設的 Twilio 設定時（ **專案設定** > **通知** > **通知設定** > **Twilio 設定** ），傳給專案成員的簡訊和電話會透過該帳戶、從其電話號碼送出。請改為將這些號碼加入白名單。
- **您使用自行託管的安裝。** 簡訊和電話來自管理員設定的 Twilio 號碼：專案的預設 Twilio 設定，或 **Admin Dashboard** > **設定** > **Call and SMS** 下適用於整個安裝的設定。請向管理員詢問應將哪些號碼加入白名單。
