# 工作流程概觀

工作流程讓你不必寫程式就能把 OneUptime 裡的工作自動化。在畫布上放幾個區塊、把它們連起來，你就有了一套自動化——只要有事情發生就會執行：事件開啟、排程到點，或是別的工具把資料送進 OneUptime。

你可以把工作流程想成專案的背景幫手：它們對事件做出反應、跟其他工具對話，在你專心做自己的事時默默把東西維持同步。

## 工作流程能做什麼

- **把 OneUptime 接上你其他的工具**——把事件送到 Slack、建立 Jira 工單、往你技術堆疊裡的某個 webhook 發送。
- **對 OneUptime 裡發生的事做出反應**——建立重大事件時，自動通知待命團隊並開一張工單。
- **按排程執行工作**——每五分鐘、每天晚上、每週一早上。
- **從外部接收資料**——讓其他系統透過一個專屬網址把資料推進 OneUptime。
- **重複使用常見的自動化**——做一次，然後從任何其他工作流程呼叫它。

## 工作流程如何運作

每個工作流程都有三個部分：

1. **一個觸發器**——用來啟動工作流程。它可以是一個手動按鈕、一個排程、一個傳入的 webhook，或是 OneUptime 裡的某個事件（例如新事件）。
2. **一個或多個元件**——工作流程實際做的事。傳送訊息、發出 HTTP 呼叫、跑一個簡單檢查、依條件分支。
3. **它們之間的連線**——你從一個區塊拉線到下一個區塊，藉此決定順序。

這一切都在畫布上以視覺化方式完成。大多數工作流程都不需要寫程式，不過需要的時候你也可以加一小段 JavaScript。

## 關鍵術語

| 術語                | 代表什麼意思                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------- |
| **工作流程**        | 整套自動化——一個名稱、一張畫布，以及一個開關讓你把它打開或關掉。                            |
| **觸發器**          | 第一個區塊。它決定工作流程何時執行。每個工作流程都恰好有一個觸發器。                        |
| **元件**            | 一個動作區塊——傳送訊息、發出請求、檢查條件。                                                |
| **執行**            | 工作流程跑過一次。連同時間戳記與每個區塊的輸出一起儲存。                                    |
| **全域變數**        | 一個你存一次、可以在任何工作流程裡重複使用的值（例如 API 金鑰）。                           |

## 在 OneUptime 的哪裡找到工作流程

在左側導覽中開啟 **工作流程**。這個區段裡有：

- **工作流程**——你的工作流程清單。建立新的，或開啟既有的。
- **全域變數**——所有工作流程共用的值。
- **執行與日誌**——專案中每一個工作流程的執行歷史。

開啟單一工作流程後，它自己的左側選單裡有：

- **概覽**——名稱、描述、標籤，以及 **已啟用** 開關。
- **建構器**——你設計工作流程的畫布。
- **工作流程變數**——只作用於這一個工作流程的值。
- **執行與日誌**——這個工作流程的每一次執行，含詳細內容。
- **設定**——webhook 密鑰、複製與匯出。

## 建立你的第一個工作流程

1. **建立**——先挑一個起點，然後替工作流程取名。
2. **挑一個觸發器**——手動、排程、webhook，或來自 OneUptime 的事件。
3. **加入元件**——把動作加到畫布上並連起來。
4. **把它打開**——在 **概覽** 頁面把 **已啟用** 開關打開。停用的工作流程完全不會執行，連手動都不行。
5. **測試**——在建構器上點擊 **執行工作流程**，然後看執行日誌。

## 一個簡單的例子

假設你想在每次建立重大事件時往 Slack 發訊息：

1. 建立一個叫「重大事件送到 Slack」的工作流程。
2. 挑 **On Create Incident** 觸發器。
3. 加入一個 **If / Else** 區塊。設定它檢查事件標題是否包含「Sev 1」。
4. 從 **Yes** 分支加入一個 **Slack** 區塊。挑好頻道，寫好訊息。
5. 把工作流程打開。

下次有人開出標題含「Sev 1」的事件時，Slack 就會亮起來。

## 工作流程與 OneUptime 其他部分的關係

- **監測器** 發現問題。**事件** 記錄問題。**工作流程** 對問題做出反應。
- **Runbook** 是給人看的逐步指引，工作流程則是無人值守的自動化。需要有人做判斷時用 runbook；步驟本身就是自動的時候用工作流程。
- **工作區連線**（Slack、Teams）是工作流程傳送訊息的去處。
