# 說明與支援

把 OneUptime 提供的協助指向你自己的團隊：使用者看到的支援信箱、聊天和說明頁面，**提供意見回饋** 的去向，單一登入對需要邀請的人顯示的內容，以及取得行動 App 的提示。每一項都可以保留 OneUptime 自己的設定、指向你自己的地址或連結，或是隱藏。

:::cards
- [變更協助的去向](#變更協助的去向)：Admin Dashboard 中的一個頁面。
- [每項設定會改變什麼](#每項設定會改變什麼)：每個位置、它的預設值和可選項目。
- [提供意見回饋](#提供意見回饋)：使用者所寫的內容傳送到哪裡。
- [登入訊息](#登入訊息)：應該向誰申請邀請。
:::

## 變更協助的去向

:::steps
### 開啟說明與支援
在 Admin Dashboard 中開啟 **設定**，然後在側邊選單中開啟 **說明與支援**。

### 變更一個位置
選擇它旁邊的 **變更**，選擇 **預設**、你自己的地址或連結，或是 **隱藏它**，然後選擇 **儲存**。**請求示範** 和 **回報錯誤或請求功能** 是開關，切換後立即儲存。

### 檢查使用者看到的內容
說明選單和登入畫面會在各自的設定旁顯示預覽。使用者下次開啟頁面時就會看到變更。
:::

在你變更某個位置之前，它會顯示 OneUptime 一直以來的內容，所以從未開啟此頁面的伺服器看起來和以前完全一樣。

## 每項設定會改變什麼

| 設定 | 使用者在哪裡看到 | 預設 | 你自己的 |
| --- | --- | --- | --- |
| **支援信箱** | 說明 › **支援信箱**、找不到頁面時的 **聯絡支援團隊**，以及錯誤畫面請使用者傳送支援套件的地址 | `support@oneuptime.com` | 一個電子郵件地址 |
| **聊天** | 說明 › **在 Slack 上聊天** | OneUptime 的 Slack 社群 | 一個連結。Slack 或 Microsoft Teams 連結保留其名稱；其他連結顯示為 **與支援團隊聊天** |
| **請求示範** | 說明 › **請求示範** | 顯示 | 只能隱藏 |
| **提供意見回饋** | 說明 › **提供意見回饋**，以及搜尋中的 **提供意見回饋** | 此伺服器的管理員 | 一個電子郵件地址，或你自己的頁面 |
| **說明與支援** | 頁尾中的 **說明與支援**，以及登入頁面上的 **聯絡方式** | `https://oneuptime.com/support` | 一個連結 |
| **回報錯誤或請求功能** | 產品選單底部，以及意見回饋後提供的公開 GitHub 問題 | 顯示 | 只能隱藏 |
| **取得行動 App** | **如何聯絡我**、待命設定、新成員在首頁的第一步，以及 **專案設定** 中的 **行動應用程式** | App Store 和 Google Play | 你自己的頁面，例如裝置管理工具的公司入口網站 |
| **給需要邀請的人的訊息** | 單一登入中顯示「You need to be invited.」和「No project access.」的畫面 | OneUptime 的句子 | 你自己的文字 |

除了訊息之外，每項設定也都可以隱藏。連結以 `https://`、`http://` 或 `mailto:` 開頭。其他任何類型的連結（包括 `javascript:`）都會被頁面拒絕，伺服器也會再次拒絕。

Admin Dashboard 自己的說明選單、頁尾和產品選單保留 OneUptime 的連結：它們是給此伺服器的管理員使用的，而管理員透過 OneUptime 取得伺服器方面的協助。

### 誰能看到你的連結

支援信箱和 **說明與支援** 連結也會顯示在登入頁面上，因此任何能開啟這些頁面的人都能看到它們。聊天連結和行動 App 的頁面只會傳送給已登入的使用者：聊天連結通常是加入你工作區的邀請。

## 提供意見回饋

| 選項 | 會發生什麼 |
| --- | --- |
| **預設** | 和以前一樣：透過電子郵件傳送到 **設定** › **電子郵件** 中設定的 **管理員通知電子郵件**；如果沒有設定，則保留在 **意見回饋** 中供此伺服器的管理員查看。在 OneUptime Cloud 上，它會傳送給 OneUptime 團隊。 |
| **電子郵件地址** | 透過此伺服器的電子郵件設定傳送到該地址，並附上此人的姓名和電子郵件地址，讓你的團隊可以回覆。此人會收到一份副本。 |
| **您自己的頁面** | **提供意見回饋** 會在新分頁中開啟它，例如你的服務台表單。OneUptime 不會傳送任何內容。 |
| **隱藏「提供意見回饋」** | 任何地方都不提供 **提供意見回饋**。 |

在伺服器無法傳送電子郵件期間，選擇電子郵件地址會隱藏 **提供意見回饋**，而不是接收一則無法送達你團隊的訊息，設定頁面也會說明這一點。在 **設定** › **電子郵件** 中設定電子郵件後，**提供意見回饋** 會自動恢復。

OneUptime 提出的問題（例如引導式設定有多容易）不屬於 **提供意見回饋**：它們的答案保留在 **意見回饋** 中，可以在那裡用 **詢問體驗如何** 關閉。

## 登入訊息

伺服器自己的單一登入會拒絕兩類人：沒有帳戶的人（在身分提供者不建立帳戶時顯示「You need to be invited.」），以及帳戶不屬於任何專案的人（「No project access.」）。兩者都需要邀請，所以這兩個畫面都會顯示你的訊息，說明應該向誰申請以及如何聯絡他們：

```text
Ask the IT service desk to invite you to OneUptime:
it-help@example.com or https://help.example.com/oneuptime
```

- 訊息是純文字，最多 1000 個字元，不能包含 `<` 或 `>`。
- 每一行是一個段落，其中的連結和電子郵件地址會變成連結。
- 畫面標題保持不變，行動 App 顯示同樣的文字。

## 行動 App 提示

使用你自己的頁面時，每個取得行動 App 的提示都會指向那裡：為你的頁面顯示一個以其地址命名的條碼，步驟中仍會寫明此伺服器的地址供 App 連線。隱藏時，完全沒有提示：

- **取得行動 App** 會從新成員在首頁的第一步中移除，而這些第一步仍會在此人可以被聯絡到、而且測試呼叫已送達後完成。
- **如何聯絡我** 和待命設定只提供瀏覽器。
- **行動應用程式** 會從 **專案設定** 中移除。
