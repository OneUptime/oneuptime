# モニターシークレット

シークレットを使用して、監視チェックで使用したい機密情報を保存できます。シークレットは暗号化され、安全に保存されます。

### シークレットの追加

シークレットを追加するには、OneUptime Dashboard -> モニター -> 設定 -> シークレット -> モニターシークレットの作成 に移動してください。

![シークレットの作成](/docs/static/images/CreateMonitorSecret.png)

シークレットに名前と値を設定し、**アクセス** ステップでそのシークレットを使用できるモニターを選択します。この例では `ApiKey` シークレットを追加しました。

**ご注意**: シークレットは暗号化され、安全に保存されます。保存後、シークレットの値が再び表示されることはありません — テーブル上でも、編集フォームでも、API 経由でもです。値を紛失した場合は、元の場所から取得して設定し直してください。シークレットをローテーションするには、その行の **シークレット値を更新** ボタンを使用します。削除して作り直す必要はありません。

### シークレットを使用できるモニターの選択

各シークレットには、次の 3 つのアクセスオプションのいずれかを設定します。

- **すべてのモニター**: プロジェクト内のすべてのモニターがシークレットを使用できます。後で作成するモニターも含まれます。多くのモニターで共有する認証情報に使用します。
- **特定のモニター**: 選択したモニターだけがシークレットを使用できます。これが既定のオプションで、これらのオプションが導入される前に作成されたシークレットもこのように動作します。
- **ラベル付きのモニター**: 選択したラベルのうち少なくとも 1 つが付いたモニターがシークレットを使用できます。モニターにそのラベルのいずれかを追加するとアクセスできるようになり、ラベルを外すと、そのモニターの次回の実行からアクセスできなくなります。

オプションは、シークレットの行の **編集** からいつでも変更できます。保持されるのは選択したオプションのリストだけです。**すべてのモニター** に切り替えるとシークレットのモニターとラベルのリストは空になり、**特定のモニター** と **ラベル付きのモニター** を切り替えると、切り替え前のリストが空になります。

シークレットが別のプロジェクトのモニターで使用できることはありません。

シークレットを使用できるモニターを編集できる人は、そのモニターの接続先であればどこにでもシークレットを送信できます。**すべてのモニター** の場合、プロジェクトでモニターを作成または編集できるすべての人が該当します。**ラベル付きのモニター** の場合は、モニターにそのラベルのいずれかを追加できる人も含まれます。

API では、アクセスオプションは `monitorAccess` フィールドで指定します: `All Monitors`、`Specific Monitors`、`Monitors With Labels`。`monitors` と `labels` フィールドにリストが入ります。`monitorAccess` を指定せずに作成したシークレットは `Specific Monitors` になります。

### シークレットの使用方法

シークレットは以下の監視タイプで使用できます。

- API（リクエストヘッダー、リクエスト本文、URL）
- ウェブサイト、IP、ポート、Ping、SSL証明書（URL内）
- 合成モニター、カスタムコードモニター（コード内）
- SNMPモニター（コミュニティ文字列、SNMPv3認証キー、プライバシーキー）

![シークレットの使用](/docs/static/images/UsingMonitorSecret.png)

シークレットを使用するには、シークレットを使いたいフィールドに `{{monitorSecrets.SECRET_NAME}}` を追加します。たとえば、この例ではリクエストヘッダーフィールドに `{{monitorSecrets.ApiKey}}` を追加しました。

シークレットは合成またはカスタムコードモニターのスクリプトが実行される前にプローブに注入されるため、`{{monitorSecrets.ApiKey}}` などの参照はスクリプト実行時に復号化された値として解決されます。

モニターが使用できないシークレットを参照している場合、その参照はそのまま残り、値には置き換えられません。

保存前にモニターをテストする場合、新しいモニターはどのリストにも含まれず、まだラベルもないため、**すべてのモニター** のシークレットだけが入力されます。モニターを保存した後は、そのモニターが使用できるすべてのシークレットがテストで使われます。
