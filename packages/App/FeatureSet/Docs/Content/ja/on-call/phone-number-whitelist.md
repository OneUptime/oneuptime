# 電話番号ホワイトリスト

OneUptime Cloud では、オンコールの SMS と電話は下記の番号から届きます。呼び出しがブロックされたり、消音されたり、迷惑電話として扱われたりしないよう、これらの番号を電話の許可リストに追加してください。

## OneUptime Cloud の番号

| 番号 | 国 |
| --- | --- |
| +13022917020 | アメリカ合衆国（US） |
| +447427817020 | イギリス（UK） |

## 電話で番号を許可する

:::steps
1. 両方の番号を 1 つの連絡先として電話の連絡先に保存します。たとえば「OneUptime」とします。
2. おやすみモード、集中モード、その他の消音モードを使っている場合は、その連絡先からの電話とメッセージを許可します。
3. 着信フィルタリングや迷惑電話フィルターのアプリ、または携帯電話会社の迷惑電話対策がオンになっている場合は、そこでも両方の番号を信頼済みにします。
:::

> [!TIP]
> **ユーザー設定** > **通知方法** で電話番号を追加または確認すると、これらの番号からコードが届きます。番号が届くかどうかをすばやく確認できます。

## 他の番号から呼び出しが届く場合

次の場合、呼び出しは上記以外の番号から届きます。

- **プロジェクトが独自の Twilio アカウントを使っている。** プロジェクトにプロジェクトのデフォルトとして設定された Twilio 設定がある場合（ **プロジェクト設定** > **通知** > **通知設定** > **Twilio 設定** ）、プロジェクトのメンバーへの SMS と電話はそのアカウントを通じて、そのアカウントの電話番号から送られます。代わりにそれらの番号をホワイトリストに追加してください。
- **セルフホストのインストールを使っている。** SMS と電話は、管理者が設定した Twilio の番号から届きます。プロジェクトのデフォルトの Twilio 設定か、 **Admin Dashboard** > **設定** > **Call and SMS** にあるインストール全体の設定です。ホワイトリストに追加する番号は管理者に確認してください。
