# 権限リファレンス

OneUptime が付与できるすべての権限を、ダッシュボードの権限ピッカーとまったく同じグループ分けで掲載しています。

このページはリクエスト時に OneUptime のソースコードから生成されます。ダッシュボード、API、Terraform プロバイダーが使うのと同じリストなので、製品と食い違うことはなく、お使いのバージョンをそのまま反映します。

全体の仕組み（チーム、スコープ、オーナー、ブロック）を知りたい場合は、[ユーザー、チーム、権限](/docs/permissions/index)から読み始めてください。

**権限キー**列の値は、[API](/docs/api-reference/api-reference)、[CLI](/docs/cli/index)、[Terraform プロバイダー](/docs/terraform/index)で使用します。タイトルはダッシュボードに表示される名称です。

## ロール

{{PERMISSION_ROLE_COUNT}} 個のロールがあり、それぞれ製品領域を Admin / Member / Viewer の水準でまとめています。チームに権限を追加するとき、**ロール**ピッカーが提示するのがこれらです。

**スコープ**列は、付与時にロールを絞り込めるかどうかを示します。`すべて / 所有 / ラベル` は選択できることを、`プロジェクト全体のみ` はロールが常にプロジェクト全体に適用されることを意味します。

## 詳細権限

{{PERMISSION_GROUP_COUNT}} グループにまたがる {{PERMISSION_TOTAL_COUNT}} 個の個別機能です。**詳細**ピッカーが提示するのがこれらで、API キーに割り当てるのもこれらです。

**ラベルで制限**列は、この権限の付与を特定のラベルが付いたリソースに限定できるかどうかを示します。
