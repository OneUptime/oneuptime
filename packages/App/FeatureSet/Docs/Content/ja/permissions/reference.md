# 権限リファレンス

OneUptime が付与できるすべてのロールと権限を、ダッシュボードの権限ピッカーと同じグループにまとめて掲載しています。チーム、API キー、Terraform リソースに付与する正確な名前やキーを調べるときに使ってください。

表は、ページが表示されるときに OneUptime のソースコードから生成されます。ダッシュボード、API、Terraform プロバイダーが使うのと同じリストなので、表は常に実行中のバージョンと一致します。権限どうしの関係（チーム、スコープ、所有者、ブロック）については、まず [ユーザー、チーム、権限](/docs/permissions/index) をご覧ください。

## 表の読み方

各ロールと各権限には、次の列を持つ行があります。

- **ロール** または **権限**: ダッシュボードに表示される名前です。
- **権限キー**: [API](/docs/api-reference/api-reference)、[CLI](/docs/cli/index)、[Terraform プロバイダー](/docs/terraform/index) で使う値です。
- **スコープ**（ロールのみ）: `すべて / 所有 / ラベル` は、ロールを付与するときにその及ぶ範囲を選べることを意味します。`プロジェクト全体のみ` は、ロールが常にプロジェクト全体に適用されることを意味します。
- **ラベルで制限**（権限のみ）: `はい` は、その権限の付与を特定のラベルが付いたリソースに限定できることを意味します。
- **説明**: そのロールや権限で許可されることです。

> [!TIP]
> まずロールを選んでください。ロールは OneUptime に機能が追加されても正しいままですが、個別の権限のリストは手作業で最新に保つ必要があります。

## ロール

ロールは {{PERMISSION_ROLE_COUNT}} 個あります。そのうち Project Owner、Project Admin、Project Member、Viewer の 4 つはプロジェクト全体に及びます。それ以外のロールは、インシデントやモニターなど 1 つの製品領域を Admin、Member、Viewer のいずれかのレベルで扱います。チームの **権限** ページと API キーのページで **ロールを追加** が提示するのは、これらのロールです。
