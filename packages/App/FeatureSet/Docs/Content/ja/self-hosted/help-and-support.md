# ヘルプとサポート

OneUptime が提供するヘルプの行き先を、自分のチームに向けます。対象は、ユーザーに表示されるサポートアドレス、チャット、ヘルプページ、**フィードバックを送る** の送信先、招待が必要な人にシングルサインオンが表示する内容、モバイルアプリの入手を促す案内です。それぞれ OneUptime のデフォルトのままにすることも、独自のアドレスやリンクに向けることも、非表示にすることもできます。

:::cards
- [ヘルプの行き先を変更する](#ヘルプの行き先を変更する): Admin Dashboard の 1 ページ。
- [各設定で変わること](#各設定で変わること): すべての場所と、そのデフォルトと選択肢。
- [フィードバックを送る](#フィードバックを送る): 書かれた内容の送信先。
- [サインイン時のメッセージ](#サインイン時のメッセージ): 招待を誰に依頼すればよいか。
:::

## ヘルプの行き先を変更する

:::steps
### ヘルプとサポートを開く
Admin Dashboard で **設定** を開き、サイドメニューの **ヘルプとサポート** を開きます。

### 場所を変更する
その横の **変更** を選び、**デフォルト**、独自のアドレスまたはリンク、**非表示にする** のいずれかを選んでから、**保存** を選びます。**デモをリクエスト** と **バグを報告するか機能をリクエスト** はスイッチで、切り替えるとすぐに保存されます。

### ユーザーに見える内容を確認する
ヘルプメニューとサインイン画面は、それぞれの設定の横にプレビューされます。変更は、ユーザーが次にページを開いたときに表示されます。
:::

場所を変更するまでは、OneUptime がこれまで表示してきた内容がそのまま表示されるため、このページを一度も開かないサーバーは以前とまったく同じに見えます。

## 各設定で変わること

| 設定 | 表示される場所 | デフォルト | 独自設定 |
| --- | --- | --- | --- |
| **サポートメール** | ヘルプ › **サポートメール**、「ページが見つかりません」画面の **サポートに問い合わせる**、エラー画面がサポート用のバンドルの送信先として示すアドレス | `support@oneuptime.com` | メールアドレス |
| **チャット** | ヘルプ › **Slack でチャット** | Slack の OneUptime コミュニティ | リンク。Slack または Microsoft Teams のリンクはその名前のままで、それ以外は **サポートとチャット** と表示されます |
| **デモをリクエスト** | ヘルプ › **デモをリクエスト** | 表示 | 非表示のみ |
| **フィードバックを送る** | ヘルプ › **フィードバックを送る**、検索の **フィードバックを送る** | このサーバーの管理者 | メールアドレス、または独自のページ |
| **ヘルプとサポート** | フッターの **ヘルプとサポート**、サインインページの **お問い合わせ** | `https://oneuptime.com/support` | リンク |
| **バグを報告するか機能をリクエスト** | 製品メニューの下部と、フィードバックの後に提案される公開の GitHub Issue | 表示 | 非表示のみ |
| **モバイルアプリを入手** | **私への連絡方法**、オンコール設定、ホームでの新しいメンバーの最初のステップ、**プロジェクト設定** の **モバイルアプリ** | App Store と Google Play | 独自のページ (デバイス管理ツールの企業ポータルなど) |
| **招待が必要な人へのメッセージ** | 「You need to be invited.」と「No project access.」と表示するシングルサインオンの画面 | OneUptime の文 | 独自の文言 |

メッセージ以外のすべての設定は、非表示にすることもできます。リンクは `https://`、`http://`、`mailto:` のいずれかで始まります。それ以外の種類のリンクは、`javascript:` も含めて、ページで拒否され、サーバーでも再度拒否されます。

Admin Dashboard 自体のヘルプメニュー、フッター、製品メニューは OneUptime のリンクのままです。これらはこのサーバーの管理者向けで、管理者はサーバーについてのヘルプを OneUptime から受けるためです。

### リンクを読める人

サポートアドレスと **ヘルプとサポート** のリンクはサインインページにも表示されるため、それらのページを開ける人なら誰でも読めます。チャットのリンクとモバイルアプリのページは、サインインしている人にだけ送られます。チャットのリンクは、多くの場合ワークスペースへの招待だからです。

## フィードバックを送る

| 選択肢 | 動作 |
| --- | --- |
| **デフォルト** | これまでどおり、**設定** › **メール** で設定した **管理者通知メール** にメールで送られます。設定されていない場合は、**フィードバック** にこのサーバーの管理者向けに保存されます。OneUptime Cloud では OneUptime チームに送られます。 |
| **メールアドレス** | このサーバーのメール設定を使い、送った人の名前とメールアドレスを付けてそのアドレスにメールで送られるので、チームが返信できます。送った人にはコピーが届きます。 |
| **独自のページ** | **フィードバックを送る** で、ヘルプデスクのフォームなどのページが新しいタブで開きます。OneUptime からは何も送信されません。 |
| **「フィードバックを送る」を非表示にする** | **フィードバックを送る** はどこにも表示されません。 |

サーバーがメールを送信できない間は、メールアドレスを選ぶと、チームに届かないメッセージを受け付ける代わりに **フィードバックを送る** が非表示になり、設定ページにもそう表示されます。**設定** › **メール** でメールを設定すると、**フィードバックを送る** は自動的に戻ります。

ガイド付きセットアップがどれだけ簡単だったかなど、OneUptime が尋ねる質問は **フィードバックを送る** ではありません。その回答は **フィードバック** に残り、そこで **どうだったかを尋ねる** をオフにすると質問されなくなります。

## サインイン時のメッセージ

サーバー自体のシングルサインオンは、2 種類の人を受け付けません。プロバイダーがアカウントを作成しない状態でアカウントを持っていない人 (「You need to be invited.」) と、アカウントがどのプロジェクトにも属していない人 (「No project access.」) です。どちらも招待が必要なため、どちらの画面にもあなたのメッセージが表示され、誰に依頼すればよいかとその連絡方法を伝えます。

```text
Ask the IT service desk to invite you to OneUptime:
it-help@example.com or https://help.example.com/oneuptime
```

- メッセージは最大 1000 文字のプレーンテキストで、`<` や `>` は使えません。
- 各行が 1 つの段落になり、その中のリンクとメールアドレスはリンクになります。
- 画面のタイトルはそのままで、モバイルアプリにも同じ文言が表示されます。

## モバイルアプリの案内

独自のページを設定すると、モバイルアプリの入手を促すすべての案内がそのページを指します。ページの QR コードが 1 つ表示され、そのアドレスが名前として付きます。手順には、アプリの接続先としてこのサーバーのアドレスが引き続き示されます。非表示にすると、案内はまったく表示されません。

- **モバイルアプリを入手** は、ホームでの新しいメンバーの最初のステップからなくなります。最初のステップは、その人に連絡でき、テスト呼び出しが届いた時点で引き続き完了します。
- **私への連絡方法** とオンコール設定では、ブラウザーだけが提示されます。
- **モバイルアプリ** は **プロジェクト設定** からなくなります。
