# Справочник разрешений

Все роли и разрешения, которые может выдать OneUptime, сгруппированные так же, как их группирует выбор разрешений в панели управления. На этой странице можно найти точное название или ключ, который нужно выдать команде, ключу API или ресурсу Terraform.

Таблицы формируются из исходного кода OneUptime в момент открытия страницы: это тот же список, который используют панель управления, API и провайдер Terraform. Поэтому они всегда соответствуют версии, которую вы запускаете. Как разрешения связаны между собой (команды, области, владельцы и блокировки), см. в разделе [Пользователи, команды и разрешения](/docs/permissions/index).

## Как читать таблицы

У каждой роли и каждого разрешения есть строка с такими столбцами:

- **Роль** или **Разрешение**: название, которое показывает панель управления.
- **Ключ разрешения**: значение для [API](/docs/api-reference/api-reference), [CLI](/docs/cli/index) и [провайдера Terraform](/docs/terraform/index).
- **Область** (только у ролей): `Все, Свои или Метки` означает, что при выдаче роли вы выбираете, насколько далеко она распространяется. `Только на весь проект` означает, что роль всегда действует во всём проекте.
- **Ограничение по меткам** (только у разрешений): `Да` означает, что выдачу этого разрешения можно ограничить ресурсами с определёнными метками.
- **Описание**: что разрешает роль или разрешение.

> [!TIP]
> Начинайте с роли. Роли остаются верными, когда в OneUptime появляются новые функции, а список отдельных разрешений приходится поддерживать в актуальном состоянии вручную.
