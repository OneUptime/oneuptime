# Справочник разрешений

Все разрешения, которые может выдать OneUptime, сгруппированные ровно так же, как их группирует выбор разрешений в панели управления.

Эта страница формируется из исходного кода OneUptime в момент запроса — из того же списка, который используют панель управления, API и провайдер Terraform. Она не может разойтись с продуктом и отражает ту версию, которую вы запустили.

Если вы ищете, как всё устроено — команды, области действия, владельцы, блокировки — начните с [Пользователи, команды и разрешения](/docs/permissions/index).

В столбце **Ключ разрешения** указано значение для [API](/docs/api-reference/api-reference), [CLI](/docs/cli/index) и [провайдера Terraform](/docs/terraform/index). Названия — это то, что вы видите в панели управления.
