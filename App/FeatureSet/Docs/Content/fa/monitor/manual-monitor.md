# مانیتور دستی

پایش دستی به شما امکان می‌دهد مانیتورهایی بسازید که وضعیتشان کاملاً به‌صورت دستی یا از طریق API مدیریت می‌شود. OneUptime هیچ بررسی خودکاری انجام نمی‌دهد — وضعیت مانیتور را مستقیماً خودتان کنترل می‌کنید.

## نمای کلی

مانیتورهای دستی جانگهدارهایی هستند که خودتان به‌روزرسانی‌شان می‌کنید. این برای موارد زیر مفید است:

- یکپارچه‌سازی با ابزارهای پایش بیرونی که وضعیت را از طریق API OneUptime به‌روز می‌کنند
- دنبال کردن سرویس‌ها یا سامانه‌هایی که نمی‌توان به‌صورت خودکار پایششان کرد
- مدیریت حوادث مؤلفه‌هایی که بررسی سلامت خودکار ندارند
- نمایش وابستگی‌های شخص ثالثی که وضعیتشان را دستی دنبال می‌کنید

## ساخت یک مانیتور دستی

1. در داشبورد OneUptime به **Monitors** بروید
2. روی **Create Monitor** کلیک کنید
3. نوع مانیتور را **Manual** انتخاب کنید
4. برای مانیتور نام و توضیحاتی وارد کنید

## چگونه کار می‌کند

مانیتورهای دستی بازه پایش، پراب یا ارزیابی خودکار معیار ندارند. وضعیت مانیتور همان‌طور که تنظیمش کرده‌اید می‌ماند تا خودتان تغییرش دهید.

### به‌روزرسانی وضعیت

وضعیت یک مانیتور دستی را به دو روش می‌توانید به‌روزرسانی کنید:

- **داشبورد** — وضعیت مانیتور را مستقیماً از داشبورد OneUptime تغییر دهید
- **API** — وضعیت مانیتور را به‌صورت برنامه‌نویسی‌شده با API OneUptime به‌روزرسانی کنید

### حوادث و هشدارها

می‌توانید برای مانیتورهای دستی هم مانند هر نوع مانیتور دیگری حادثه و هشدار بسازید. این کار به شما امکان می‌دهد:

- زمان قطعی سرویس‌هایی را که بیرون پایش می‌شوند دنبال کنید
- وقتی مشکلی گزارش می‌شود دستی حادثه بسازید
- از مانیتورهای دستی در صفحات وضعیت استفاده کنید تا وضعیت را به کاربران اطلاع دهید
