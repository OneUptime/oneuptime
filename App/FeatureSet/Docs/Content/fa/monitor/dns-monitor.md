# مانیتور DNS

پایش DNS به شما امکان می‌دهد سلامت و درستی تفکیک نام DNS دامنه‌هایتان را پایش کنید. OneUptime به‌صورت دوره‌ای رکوردهای DNS را کوئری می‌کند و پاسخ‌ها را با معیارهای پیکربندی‌شده شما می‌سنجد.

## نمای کلی

مانیتورهای DNS سرورهای DNS را برای نوع‌های مشخصی از رکورد کوئری می‌کنند و نتایج را ارزیابی می‌کنند. این کار به شما امکان می‌دهد:

- در دسترس بودن سرویس DNS را پایش کنید
- راستی‌آزمایی کنید که رکوردهای DNS مقادیر درستی برمی‌گردانند
- زمان پاسخ تفکیک نام DNS را دنبال کنید
- پیکربندی DNSSEC را اعتبارسنجی کنید
- مشکلات انتشار DNS یا ربوده شدن آن را تشخیص دهید

## ساخت یک مانیتور DNS

1. در داشبورد OneUptime به **Monitors** بروید
2. روی **Create Monitor** کلیک کنید
3. نوع مانیتور را **DNS** انتخاب کنید
4. نام دامنه و نوع رکورد موردنظر برای کوئری را وارد کنید
5. معیارهای پایش را در صورت نیاز پیکربندی کنید

## گزینه‌های پیکربندی

### تنظیمات پایه

| فیلد        | توضیحات                                                                          | الزامی |
| ----------- | -------------------------------------------------------------------------------- | ------ |
| نام دامنه   | دامنه‌ای که باید کوئری شود (برای نمونه `example.com`)                            | بله    |
| نوع رکورد   | نوع رکورد DNS که باید کوئری شود                                                  | بله    |
| سرور DNS    | سرور DNS سفارشی (برای نمونه `8.8.8.8`). برای پیش‌فرض سامانه خالی بگذارید          | خیر    |

| نوع رکورد | توضیحات                                        |
| --------- | ---------------------------------------------- |

| AAAA      | رکوردهای آدرس IPv6                             |
| CNAME     | رکوردهای نام متعارف (نام مستعار)               |
| MX        | رکوردهای تبادل ایمیل                           |
| NS        | رکوردهای nameserver                            |
| TXT       | رکوردهای متنی (SPF، DKIM و مانند آن)           |
| SOA       | رکوردهای Start of Authority                    |
| PTR       | رکوردهای اشاره‌گر (DNS معکوس)                  |
| SRV       | رکوردهای مکان‌یاب سرویس                        |
| CAA       | رکوردهای Certificate Authority Authorization   |

## معیارهای پایش

می‌توانید معیارهایی پیکربندی کنید که تعیین کنند DNS شما بر چه پایه‌ای آنلاین، تضعیف‌شده یا آفلاین در نظر گرفته شود:

### انواع فیلتر در دسترس

| نوع فیلتر                  | توضیحات                                       |
| -------------------------- | --------------------------------------------- |
| DNS آنلاین است             | اینکه سرور DNS به کوئری‌ها پاسخ می‌دهد یا نه   |
| زمان پاسخ DNS (میلی‌ثانیه) | زمان پاسخ کوئری به میلی‌ثانیه                  |
| رکورد DNS وجود دارد        | اینکه برای این کوئری رکورد DNS وجود دارد یا نه |
| مقدار رکورد DNS            | مقداری که یک رکورد DNS برمی‌گرداند             |
| DNSSEC معتبر است           | اینکه اعتبارسنجی DNSSEC موفق است یا نه         |

### شرط‌های فیلتر

برای **DNS آنلاین است**، **رکورد DNS وجود دارد** و **DNSSEC معتبر است**:

- **درست** — شرط برقرار است
- **نادرست** — شرط برقرار نیست

برای **زمان پاسخ DNS**:

- **بزرگ‌تر از**، **کوچک‌تر از**، **بزرگ‌تر یا مساوی**، **کوچک‌تر یا مساوی**

برای **مقدار رکورد DNS**:

- **شامل است** — مقدار رکورد متن مشخص‌شده را دارد
- **شامل نیست** — مقدار رکورد متن مشخص‌شده را ندارد
- **شروع می‌شود با** — مقدار رکورد با متن مشخص‌شده شروع می‌شود
- **پایان می‌یابد با** — مقدار رکورد با متن مشخص‌شده پایان می‌یابد
- **مساوی است با** — مقدار رکورد دقیقاً مطابقت دارد
- **مساوی نیست با** — مقدار رکورد مطابقت ندارد

### نمونه معیار

#### بررسی اینکه DNS تفکیک نام انجام می‌دهد

- **نوع فیلتر**: DNS آنلاین است
- **شرط فیلتر**: درست

#### راستی‌آزمایی اینکه رکورد A به IP درست اشاره می‌کند

- **نوع فیلتر**: مقدار رکورد DNS
- **شرط فیلتر**: مساوی است با
- **مقدار**: `93.184.216.34`

#### هشدار اگر پاسخ DNS کند باشد

- **نوع فیلتر**: زمان پاسخ DNS (میلی‌ثانیه)
- **شرط فیلتر**: بزرگ‌تر از
- **مقدار**: ۵۰۰

#### راستی‌آزمایی معتبر بودن DNSSEC

- **نوع فیلتر**: DNSSEC معتبر است
- **شرط فیلتر**: درست
