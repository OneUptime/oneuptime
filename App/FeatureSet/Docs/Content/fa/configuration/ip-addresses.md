# فهرست سفید آدرس‌های IP برای OneUptime.com

اگر از OneUptime.com استفاده می‌کنید و به دلایل امنیتی می‌خواهید آدرس‌های IP ما را در فهرست سفید بگذارید، می‌توانید دستورالعمل زیر را دنبال کنید.

لطفاً آدرس‌های IP زیر را در دیوار آتش خود در فهرست سفید قرار دهید تا oneuptime.com بتواند به منابع شما دسترسی داشته باشد.

{{IP_WHITELIST}}

این آدرس‌های IP ممکن است تغییر کنند؛ اگر چنین شود، از پیش به شما اطلاع می‌دهیم.

## دریافت برنامه‌نویسی‌شده آدرس‌های IP

می‌توانید فهرست آدرس‌های IP خروجی پراب‌ها را از طریق نقطه پایانی API زیر هم دریافت کنید:

```
GET https://oneuptime.com/ip-whitelist
```

این نقطه پایانی پاسخی به‌صورت JSON برمی‌گرداند:

```json
{
  "ipWhitelist": ["<list of IPs>"]
}
```

می‌توانید با این نقطه پایانی فهرست سفید دیوار آتش خود را به‌صورت خودکار به‌روز نگه دارید.
