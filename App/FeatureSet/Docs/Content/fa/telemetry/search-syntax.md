# نحو جستجوی تله‌متری

## نمای کلی

جعبه جستجوی بالای کاوشگرهای Logs، Traces، Metrics و Exceptions همگی یک زبان را حرف می‌زنند. پرس‌وجو فهرستی از پالایه‌هاست که با فاصله جدا شده‌اند، و **هر پالایه باید بخواند** — میان پالایه‌ها هیچ OR ضمنی‌ای وجود ندارد.

```
severity:error @platform.team:a* -@http.method:GET timeout
```

این چنین خوانده می‌شود: گزارش‌های سطح خطا، که ویژگی `platform.team` آن‌ها با `a` آغاز می‌شود، که ویژگی `http.method` آن‌ها `GET` نیست، و که پیامشان به `timeout` اشاره می‌کند.

## دو گونه پالایه

| شکل | چه چیزی را می‌پالاید | نمونه |
| --- | --- | --- |
| `field:value` | فیلدی توکار از سیگنال | `severity:error` |
| `@attribute:value` | ویژگی OpenTelemetry روی سطر | `@http.status_code:500` |
| واژه‌های خالی | پیام (گزارش‌ها)، نام اسپن (ردیابی‌ها)، نام سنجه (سنجه‌ها) | `connection refused` |

یک `key:value` خالی که کلیدش فیلدی شناخته نیست به‌عنوان ویژگی رفتار می‌شود، پس `k8s.pod:api-0` و `@k8s.pod:api-0` یک معنا دارند. پیشوند `@` هرگز اشتباه نیست و همیشه یعنی «در ویژگی‌ها بگرد».

متنی که صرفاً اتفاقاً دونقطه دارد متن می‌ماند — `https://example.com` و `12:30` به‌عنوان واژه جستجو می‌شوند، نه پالایه خوانده می‌شوند.

## تطبیق مقادیر

هرچه در این جدول است روی هم فیلد و هم ویژگی کار می‌کند.

| آنچه تایپ می‌کنید | با چه می‌خواند |
| --- | --- |
| `@k:abc` | دقیقاً `abc` |
| `@k:a*` | هر چیزی که با `a` آغاز شود — `abc`، `alpha` |
| `@k:*c` | هر چیزی که به `c` ختم شود |
| `@k:a*c` | با `a` آغاز و به `c` ختم شود |
| `@k:a?c` | `?` دقیقاً یک نویسه است — `abc`، `axc`، اما نه `ac` |
| `@k:*` | ویژگی حاضر است، با هر مقداری |
| `@k:~abc` | هر جایی `abc` را دربر دارد |
| `@k:!abc` | هر چیزی جز `abc` |
| `@k:>100` | بزرگ‌تر از ۱۰۰. همچنین `>=`، `<`، `<=` |
| `@k:(a OR b)` | هرکدام از دو مقدار. `@k:[a, b]` همان است |
| `@k:(a* OR b*)` | هرکدام از دو الگو |

تطبیق جانشین و «دربر دارد» به بزرگی و کوچکی حروف بی‌اعتنایند؛ تطبیق دقیق نه، چون دقیقاً با مقداری که ذخیره شده مقایسه می‌شود.

### مقادیر دارای فاصله

مقدار را در گیومه دوتایی بپیچید:

```
name:"SELECT wp_options"
@k8s.container.name:"my container"
```

گیومه‌ها از **فاصله‌ها** محافظت می‌کنند، نه از جانشین‌ها — `@k:"a b*"` همچنان با هر چیزی که با `a b` آغاز شود می‌خواند.

### `*`، `?` و دیگر نشانه‌گذاری‌های تحت‌اللفظی

بک‌اسلش نویسه بعدی را تحت‌اللفظی می‌کند:

| آنچه تایپ می‌کنید | با چه می‌خواند |
| --- | --- |
| `@k:a\*b` | دقیقاً `a*b` |
| `@k:\~abc` | دقیقاً `~abc` |
| `@k:\>5` | دقیقاً `>5` |

مقادیری که `%` یا `_` دارند به گریز نیازی ندارند — همیشه تحت‌اللفظی‌اند.

## کنار گذاشتن

یک `-` پیشرو هر پالایه‌ای را وارونه می‌کند، از جمله آن‌های بالا:

| آنچه تایپ می‌کنید | با چه می‌خواند |
| --- | --- |
| `-severity:debug` | همه‌چیز جز debug |
| `-@platform.team:a*` | هر چیزی که `platform.team` آن با `a` آغاز **نشود**، از جمله سطرهایی که اصلاً `platform.team` ندارند |
| `-@k:*` | ویژگی نیست یا خالی است |
| `-@k:(a OR b)` | هیچ‌کدام از دو مقدار |
| `-@k:>100` | ۱۰۰ یا کمتر |
| `-@k:~abc` | `abc` را دربر ندارد |

## فیلدها به تفکیک سیگنال

### گزارش‌ها

| فیلد | نام‌های مستعار | یادداشت‌ها |
| --- | --- | --- |
| `severity` | `level` | `fatal`، `error`، `warning`، `info`، `debug`، `trace` — با هر بزرگی و کوچکی |
| `service` | | نام سرویس |
| `trace` | | شناسه ردیابی |
| `span` | | شناسه اسپن |
| `message` | `msg`، `log`، `body` | خط گزارش. واژه‌های خالی هم همین را جستجو می‌کنند |

### ردیابی‌ها

| فیلد | یادداشت‌ها |
| --- | --- |
| `service` | نام سرویس |
| `name` | نام اسپن. واژه‌های خالی هم همین را جستجو می‌کنند |
| `status` | `ok`، `error`، `unset` |
| `kind` | `server`، `client`، `producer`، `consumer`، `internal` |
| `duration` | میلی‌ثانیه، برای نمونه `duration:>500` |
| `statusMessage` | متن پیام وضعیت |
| `hasException` | `true` یا `false` |
| `trace`، `span` | شناسه‌ها |

### سنجه‌ها

| فیلد | یادداشت‌ها |
| --- | --- |
| `name` | نام سنجه. واژه‌های خالی هم همین را جستجو می‌کنند |
| `service` | نام سرویس |

### استثناها

| فیلد | یادداشت‌ها |
| --- | --- |
| `type` | نوع استثنا، برای نمونه `type:TypeError` |
| `env` | محیط |
| `service` | نام سرویس |

## ترکیب پالایه‌ها

پالایه‌ها با AND ترکیب می‌شوند. می‌توان `AND` را میانشان نوشت و هیچ فرقی نمی‌کند:

```
severity:error service:api          # both must hold
severity:error AND service:api      # identical
```

**میان** پالایه‌ها OR وجود ندارد. برای تطبیق با هرکدام از دو مقدار برای یک کلید، از شکل «هرکدام از» استفاده کنید:

```
@http.method:(GET OR POST)
```

دو پالایه روی یک کلید با AND ترکیب می‌شوند، که همین‌گونه بازه یا الگویی دوطرفه نوشته می‌شود:

```
@duration:>=100 @duration:<=500
@k:a* @k:*z
```

## نشان‌ها و جعبه جستجو

زدن Enter روی یک عبارت `key:value` آن را به نشانی بالای نتایج تبدیل می‌کند. نشان مقدار را دقیقاً همان‌طور که تایپ شده حمل می‌کند، پس جانشین جانشین می‌ماند. کلیک روی مقداری در نوار کناری وجه‌ها همان نوع نشان را با مقدار گریزخورده می‌افزاید — مقداری ذخیره‌شده که اتفاقاً `*` دارد برای همان مقدار تحت‌اللفظی می‌پالاید، نه به‌عنوان الگو.

نشان‌ها بخشی از نمای ذخیره‌شده و نشانی صفحه‌اند، پس پالایه از تازه‌سازی، نشانک و پیوند به اشتراک گذاشته‌شده جان به در می‌برد.

## یادداشت‌ها

- **کلید** ویژگی‌ها برای پالایه‌های جانشین، «دربر دارد» و پیشوند/پسوند بدون حساسیت به بزرگی و کوچکی حروف تطبیق می‌شوند، پس لازم نیست به یاد بیاورید که `requestId` دریافت شده بود یا `requestid`.
- پالایه `-@k:...` با سطرهایی که هرگز آن ویژگی را نداشته‌اند هم می‌خواند — سطری که اصلاً `platform.team` را حمل نمی‌کند بدیهی است که با `a` آغاز نمی‌شود.
- مقایسه‌های عددی روی مقادیر ویژگی‌ای که به‌صورت متن ذخیره شده‌اند کار می‌کنند؛ مقداری که عدد نیست هرگز یکی را برآورده نمی‌کند.
