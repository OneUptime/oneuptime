# پرسش‌های متداول و رفع اشکال

پرسش‌های پرتکرار و راه‌حل‌ها برای اپلیکیشن‌های موبایل و دسکتاپ OneUptime.

## OneUptime اپلیکیشن‌هایش را چگونه توزیع می‌کند؟

- **موبایل (iOS و Android):** OneUptime یک اپلیکیشن بومی به نام **OneUptime On-Call** منتشر می‌کند. این اپلیکیشن در [Apple App Store](https://apps.apple.com/us/app/oneuptime-on-call/id6759615391) و [Google Play](https://play.google.com/store/apps/details?id=com.oneuptime.oncall) منتشر شده است. برای دستگاه‌های Android بدون Google Play، یک [دانلود APK](https://github.com/OneUptime/oneuptime/releases/latest/download/oneuptime-on-call-android-app.apk) امضاشده هم در دسترس است.
- **دسکتاپ (Windows، macOS، Linux):** داشبورد وب OneUptime یک Progressive Web App (PWA) است. می‌توانید آن را مستقیماً از یک مرورگر مبتنی بر Chromium یا Safari به‌عنوان اپلیکیشن دسکتاپ نصب کنید — بدون نیاز به حساب فروشگاه.

## پرسش‌های متداول اپلیکیشن موبایل

### چه دستگاه‌هایی پشتیبانی می‌شوند؟

- **iOS:** iPhone یا iPad با iOS 15.0 یا بالاتر.
- **Android:** گوشی‌ها و تبلت‌ها با Android 8.0 (Oreo) یا بالاتر.

### آیا اپلیکیشن رایگان است؟

بله. نصب اپلیکیشن OneUptime On-Call رایگان است. با حساب OneUptime موجود خود وارد می‌شوید.

### آیا می‌توانم اپلیکیشن را با یک نمونه خودمیزبان OneUptime استفاده کنم؟

بله. در اولین اجرا، اپلیکیشن یک **نشانی سرور** می‌خواهد. نشانی نمونه خودمیزبان خود را وارد کنید (برای نمونه `https://oneuptime.example.com`). اپلیکیشن پیش از اجازه ورود، در دسترس بودن سرور را اعتبارسنجی می‌کند.

برای اعلان‌های پوش روی نمونه‌های خودمیزبان، راهنمای [اعلان‌های پوش](/docs/self-hosted/push-notifications) را دنبال کنید.

### به‌روزرسانی‌ها چگونه تحویل می‌شوند؟

- **iOS:** از طریق App Store. در **Settings → App Store** به‌روزرسانی خودکار را فعال کنید، یا از پروفایل App Store خود دستی به‌روزرسانی کنید.
- **Android (Google Play):** به‌روزرسانی خودکار به‌صورت پیش‌فرض فعال است.
- **Android (بارگذاری جانبی APK):** تازه‌ترین APK را از پیوند GitHub Releases بالا دانلود و نصب کنید.

### چرا اعلان پوش دریافت نمی‌کنم؟

پوش موبایل از APNs (در iOS) و FCM (در Android) از طریق Expo Push استفاده می‌کند. این‌ها را بررسی کنید:

1. اعلان‌ها در سطح سیستم‌عامل برای **OneUptime On-Call** فعال باشد.
2. بهینه‌سازی باتری خاموش و فعالیت پس‌زمینه مجاز باشد (Android).
3. حالت‌های مزاحم نشوید یا Focus خاموش باشند، یا اپلیکیشن در فهرست استثناها باشد.
4. وارد شده باشید — توکن پوش فقط پس از ورود شما در سرور ثبت می‌شود.
5. **فقط خودمیزبان:** اعلان‌های پوش روی نمونه OneUptime شما پیکربندی شده باشد. راهنمای [اعلان‌های پوش](/docs/self-hosted/push-notifications) را ببینید.

### آیا داده روی گوشی من امن است؟

- همه ترافیک API از HTTPS استفاده می‌کند.
- توکن‌های دسترسی و تازه‌سازی در انبار امن کلید دستگاه ذخیره می‌شوند (Keychain در iOS، Keystore در Android).
- می‌توانید از صفحه **Settings** درون اپلیکیشن، باز کردن با Face ID / Touch ID / اثر انگشت را الزامی کنید.

### آیا می‌توانم اپلیکیشن را روی چند دستگاه نصب کنم؟

بله. با همان حساب OneUptime روی هر تعداد دستگاهی که لازم دارید وارد شوید. هر دستگاه اعلان‌های پوش خودش را دریافت می‌کند.

### چگونه حذفش کنم؟

- **iOS:** آیکون را نگه دارید → **Remove App** → **Delete App**.
- **Android:** آیکون را نگه دارید → **Uninstall**، یا **Settings → Apps → OneUptime On-Call → Uninstall**.

حساب و داده OneUptime شما روی سرور ذخیره می‌شود و با حذف اپلیکیشن پاک نمی‌شود.

## پرسش‌های متداول اپلیکیشن دسکتاپ (PWA)

### Progressive Web App (PWA) چیست؟

یک Progressive Web App برنامه‌ای تحت وب است که می‌توان آن را مانند یک اپلیکیشن بومی دسکتاپ نصب کرد. پس از نصب، در پنجره اختصاصی خود اجرا می‌شود، آیکون خودش را در اجراکننده برنامه‌ها دارد و می‌تواند اعلان دسکتاپ برساند — بدون گذر از Windows Store، Mac App Store یا هر کانال توزیع دیگری.

### چرا اپلیکیشن دسکتاپ از فناوری PWA استفاده می‌کند؟

- **به‌روزرسانی فوری** — اپلیکیشن همان لحظه که استقرار می‌دهید با نمونه OneUptime شما هماهنگ می‌ماند.
- **بدون نیاز به حساب فروشگاه** — مستقیماً از هر مرورگر مدرنی نصب کنید.
- **یک کدبیس واحد** — همان داشبورد روی Windows، macOS و Linux اجرا می‌شود.

### چرا دکمه «Install» ظاهر نمی‌شود؟

1. از مرورگری مبتنی بر Chromium (Chrome، Edge، Brave، Arc) یا Safari (macOS Sonoma به بالا) استفاده کنید.
2. مطمئن شوید نمونه OneUptime شما روی HTTPS با گواهی معتبر ارائه می‌شود.
3. کش مرورگر خود را پاک کنید و صفحه را دوباره بارگذاری کنید.
4. ممکن است اپلیکیشن از قبل نصب باشد — Applications / منوی Start خود را بررسی کنید.

### چگونه اپلیکیشن دسکتاپ را به‌روزرسانی کنم؟

PWA هر بار که آن را در حالت آنلاین باز کنید به‌صورت خودکار به‌روزرسانی می‌شود. برای به‌روزرسانی اجباری، پنجره را با **Ctrl+R** (Windows/Linux) یا **Cmd+R** (macOS) تازه کنید.

### چگونه PWA دسکتاپ را حذف کنم؟

- **Windows:** **Settings → Apps → OneUptime → Uninstall**، یا روی مدخل منوی Start راست‌کلیک کنید.
- **macOS:** اپلیکیشن را از **Applications** به سطل زباله بکشید، یا روی آیکون Dock راست‌کلیک کنید و **Remove** را بزنید.
- **Linux:** از گزینه حذف در اجراکننده برنامه‌های خود استفاده کنید، یا فایل `.desktop` مربوط را حذف کنید.

## رفع اشکال

### مشکلات اپلیکیشن موبایل

**اپلیکیشن وارد نمی‌شود / «Network Error»:**

- مطمئن شوید **نشانی سرور** درست و از گوشی شما در دسترس است.
- بررسی کنید که گوشی شما به اینترنت متصل است.
- برای نمونه‌های خودمیزبان پشت VPN، مطمئن شوید VPN فعال است.

**اعلان‌های پوش با تأخیر یا اصلاً نمی‌رسند (Android):**

- بهینه‌سازی باتری را خاموش کنید: **Settings → Apps → OneUptime On-Call → Battery → Unrestricted**.
- Data Saver را برای اپلیکیشن خاموش کنید.
- روی دستگاه‌های Samsung، **Device care → Battery → Background usage limits** را برای OneUptime On-Call خاموش کنید.

**اعلان‌های پوش با تأخیر یا اصلاً نمی‌رسند (iOS):**

- اپلیکیشن را به‌زور نبندید — iOS ممکن است تحویل در پس‌زمینه را متوقف کند.
- در زمان آنکال بودن، Low Power Mode را خاموش کنید.
- OneUptime On-Call را به فهرست مجاز هر حالت Focus فعال اضافه کنید.

**Face ID / Touch ID / اثر انگشت کار نمی‌کند:**

- مطمئن شوید زیست‌سنجی در تنظیمات سیستم‌عامل شما ثبت شده است.
- باز کردن با زیست‌سنجی را از صفحه **Settings** درون اپلیکیشن OneUptime On-Call دوباره فعال کنید.

### مشکلات اپلیکیشن دسکتاپ (PWA)

**دکمه نصب نیست:**

- از مرورگری پشتیبانی‌شده استفاده کنید (مبتنی بر Chromium یا Safari روی macOS Sonoma به بالا).
- مطمئن شوید نمونه OneUptime روی HTTPS ارائه می‌شود.
- منتظر بمانید تا صفحه کامل بارگذاری شود، سپس نوار نشانی را برای آیکون نصب بررسی کنید.

**اعلان‌های دسکتاپ ظاهر نمی‌شوند:**

- وقتی مرورگر اجازه خواست، اعلان‌ها را مجاز کنید.
- تنظیمات اعلان سیستم‌عامل را بررسی کنید (Focus Assist در Windows، Notifications در macOS، دیمن اعلان در Linux).
- برای نمونه‌های خودمیزبان، مطمئن شوید پیکربندی [اعلان‌های پوش](/docs/self-hosted/push-notifications) کامل است.

**اپلیکیشن تازه‌ترین داده را نشان نمی‌دهد:**

- با **Ctrl+R** / **Cmd+R** تازه کنید.
- پنجره را ببندید و دوباره باز کنید.
- اتصال شبکه خود را بررسی کنید.
