# راهنمای نصب روی Linux

OneUptime را به‌عنوان یک اپلیکیشن دسکتاپ روی توزیع‌های Linux نصب کنید تا پایش و مدیریت حادثه کامل داشته باشید.

## روش‌های نصب

### روش ۱: Google Chrome/Chromium (توصیه‌شده)

Chrome و Chromium بهترین تجربه PWA را روی Linux با یکپارچگی بومی دسکتاپ فراهم می‌کنند.

#### مراحل نصب PWA:

1. **OneUptime را در Chrome/Chromium باز کنید**

   - مرورگر خود را اجرا کنید
   - به نشانی نمونه OneUptime خود بروید
   - وارد حساب OneUptime خود شوید
   - منتظر بمانید تا صفحه کامل بارگذاری شود

2. **نصب PWA**

   - در نوار نشانی به دنبال **آیکون نصب** (⊞) بگردید
   - روی **«Install OneUptime»** کلیک کنید
   - یا از **منوی Chrome** (⋮) → **More tools** → **Create shortcut** استفاده کنید

3. **گزینه‌های نصب**

   - برای تجربه‌ای شبیه اپلیکیشن بومی، **«Open as window»** را علامت بزنید
   - در صورت تمایل نام اپلیکیشن را تغییر دهید
   - ساخت میان‌بر روی دسکتاپ را انتخاب کنید
   - روی **«Install»** یا **«Create»** کلیک کنید

4. **اجرای اپلیکیشن**
   - OneUptime را در اجراکننده برنامه‌ها پیدا کنید
   - یا از میان‌بر دسکتاپ استفاده کنید
   - اپلیکیشن در پنجره اختصاصی خود باز می‌شود

### روش ۲: Firefox

Firefox از نصب PWA روی Linux با یکپارچگی پایه‌ای دسکتاپ پشتیبانی می‌کند.

1. **نصب PWA**:
   - OneUptime را در Firefox باز کنید
   - به دنبال بنر یا پیام نصب بگردید
   - در صورت نمایش، روی **«Install»** کلیک کنید
   - توجه: یکپارچگی دسکتاپ در مقایسه با Chrome محدودتر است

### روش ۳: Microsoft Edge

Edge روی Linux در دسترس است و پشتیبانی خوبی از PWA دارد.

1. **نصب PWA**: همان مراحل روش Chrome را دنبال کنید

## به‌روزرسانی و نگهداری

### به‌روزرسانی خودکار

PWA مربوط به OneUptime به‌صورت خودکار به‌روزرسانی می‌شود:

- به‌روزرسانی‌ها هنگام تازه‌سازی اپلیکیشن توسط مرورگر اعمال می‌شوند
- به‌روزرسانی‌های امنیتی حیاتی بی‌درنگ منتشر می‌شوند
- به دخالت دستی نیازی نیست

## حذف نصب

### حذف بر اساس مرورگر

```bash
# Chrome PWA management
google-chrome chrome://apps/

# Remove all OneUptime-related browser data
rm -rf ~/.config/google-chrome/Default/Local\ Storage/leveldb/
rm -rf ~/.cache/google-chrome/Default/
```
