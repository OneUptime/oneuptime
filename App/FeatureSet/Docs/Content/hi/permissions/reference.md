# अनुमति संदर्भ

OneUptime जो भी अनुमतियाँ दे सकता है, वे सब यहाँ हैं — ठीक उसी तरह समूहीकृत जैसे डैशबोर्ड का अनुमति चयनकर्ता उन्हें समूहीकृत करता है।

यह पृष्ठ अनुरोध के समय OneUptime के स्रोत कोड से बनाया जाता है — उसी सूची से जिसका उपयोग डैशबोर्ड, API और Terraform प्रोवाइडर करते हैं। यह उत्पाद से अलग नहीं हो सकता और आप जो संस्करण चला रहे हैं उसी को दर्शाता है।

यदि आप जानना चाहते हैं कि सब कुछ आपस में कैसे जुड़ता है — टीमें, दायरे, स्वामी, ब्लॉक — तो [उपयोगकर्ता, टीमें और अनुमतियाँ](/docs/permissions/index) से शुरू करें।

**अनुमति कुंजी** स्तंभ का मान [API](/docs/api-reference/api-reference), [CLI](/docs/cli/index) और [Terraform प्रोवाइडर](/docs/terraform/index) के साथ उपयोग होता है। शीर्षक वही हैं जो आप डैशबोर्ड में देखते हैं।

## भूमिकाएँ
