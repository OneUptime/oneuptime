# Ресурсы и группы

Ресурс — это одна строка на вашей странице статуса — монитор (или группа мониторов) с именем, понятным посетителям, текущим статусом и, при желании, числом аптайма и графиком истории. Группа — это раздел, содержащий ресурсы, поэтому страница с сорока мониторами читается как «API», «Веб-приложение» и «Конвейер данных» вместо одного бесконечного списка.

Вы собираете и то и другое на одном экране. Откройте страницу статуса и выберите **Resources** в боковом меню (пункт называется **Monitors** в проектах, где группы мониторов не включены). Раньше группы жили на отдельной странице; теперь это не так, и старый URL `/groups` просто перенаправляет сюда.

Сделайте эту часть правильно, и всё остальное на странице статуса — просто украшение. Посетители судят «это у меня или у них?» по этим строкам, поэтому называйте их так, как клиенты говорят о вашем продукте, — **Checkout API**, а не `prod-checkout-lb-healthcheck-us-east-1`.

## Экран Resources

Экран разделён на две части. Слева — навигатор со списком всех групп на странице; справа — содержимое выбранной группы.

- **Навигатор групп (слева)** — дерево групп с полем поиска (**Search groups...**) сверху и счётчиком снизу, вроде `3 groups · 12 resources`. Когда групп больше, чем помещается, появляется кнопка **Show N more of M**.
- **Top of page** — первая строка в навигаторе. В ней находятся ресурсы, не входящие ни в одну группу, а её подсказка прямо объясняет, что это значит: посетители видят их первыми, выше любой группы. Если на странице вообще нет групп, правая панель называется **All resources**.
- **Панель ресурсов (справа)** — озаглавлена именем выбранной группы. В её заголовке находятся **Edit Group**, основная кнопка **Add Monitor** и переполнение **More actions**.

Две кнопки находятся прямо в заголовке карточки: **New Group** и меню из трёх точек с пунктами **Import groups from CSV** и **Refresh**.

Описание карточки меняется в зависимости от формы вашей страницы. При наличии групп оно говорит, что это всё, что видят посетители, и предлагает выбрать группу слева, чтобы отредактировать её содержимое. Если групп ещё нет, оно подсказывает создать группу, чтобы разбить более длинную страницу на разделы.

**Пустые состояния подсказывают, что делать.** Пустая группа показывает **No monitors here yet** с кнопками **Add Monitor**, **Add Multiple** и — только если на странице статуса вообще нет групп — **Create a Group**. Поиск, не давший результатов, показывает **No resources match your search**. Пустой навигатор говорит, что группы разбивают более длинную страницу статуса на разделы и что они могут быть вложенными.

## Добавление монитора

Выберите группу, в которую должен попасть ресурс (или **Top of page** для строки без группы), затем нажмите **Add Monitor**. Модальное окно называется **Add a monitor to {group}** и состоит из двух шагов: **Monitor Details** и **Advanced**.

На шаге **Monitor Details**:

- **Monitor** — выпадающий список мониторов вашего проекта, плейсхолдер **Select Monitor**. Обязательно.
- **Display Name** — обязательно. Это текст, который читают посетители, и он хранится отдельно от собственного имени монитора, так что вы можете переименовать его здесь, не трогая мониторинг.
- **Description** — необязательный markdown, показываемый под строкой. Хорошо подходит для предложения, объясняющего, что на самом деле делает сервис.

Если в вашем проекте включены группы мониторов, под выпадающим списком появляется ссылка **Add a Monitor Group instead.** — нажмите её, и выпадающий список **Monitor** заменится на **Monitor Group** (**Select Monitor Group**). Ссылка после этого переключается на **Add a Monitor instead.**, чтобы можно было вернуться назад. Используйте группу мониторов, когда хотите, чтобы одна строка на странице представляла несколько проверок, объединённых вместе.

### Добавление нескольких сразу

**Add Multiple** (также доступно как **Add multiple monitors** в меню **More actions**) открывает **Add Multiple Monitors**. У него те же два шага, но первый — это мультивыбор **Monitors** вместо одного выпадающего списка, а параметры отображения, которые вы выбираете на шаге **Advanced**, применяются ко всем выбранным мониторам. Это самый быстрый способ наполнить новую страницу.

## Параметры отображения ресурса

Шаг **Advanced** одинаков в форме добавления одного ресурса и в модальном окне массового добавления. Всё здесь настраивается для каждого ресурса отдельно — две строки в одной группе могут быть настроены по-разному.

| Поле                                                      | Назначение                                                                                              |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| **Tooltip** (`displayTooltip`)                                | Дополнительный текст, показываемый рядом с ресурсом на вашей странице статуса. Используйте для охвата: «клиенты США и ЕС». |
| **Show Current Resource Status** (`showCurrentStatus`)        | Включено по умолчанию. Показывает текущий статус — работает, деградация, недоступен — рядом со строкой.  |
| **Show Uptime %** (`showUptimePercent`)                       | Выключено по умолчанию. Показывает процент аптайма рядом с ресурсом.                                      |
| **Select Uptime Precision** (`uptimePercentPrecision`)         | Появляется только когда включён **Show Uptime %**. Обязательно, по умолчанию один десятичный знак.        |
| **Show Status History Chart** (`showStatusHistoryChart`)      | Включено по умолчанию. Показывает столбчатую диаграмму истории аптайма по дням для ресурса.               |

**Display Name** (`displayName`) и **Description** (`displayDescription`) с первого шага тоже влияют только на отображение — они никогда не меняют сам монитор.

## Проценты аптайма и графики истории

И **Show Uptime %**, и **Show Status History Chart** зависят от настройки, которая находится в другом месте. Период, который они охватывают, — это **Show Uptime History (in days)** в **Status Pages → ваша страница → Advanced → Advanced Settings**, в карточке **Uptime History Settings**. Принимает значения от 1 до 90 дней, по умолчанию 90.

Так что порядок действий такой: включите переключатели для каждого ресурса, затем один раз задайте период для всей страницы.

**Точность — вопрос суждения.** Выпадающий список **Select Uptime Precision** предлагает `99% (No Decimal)`, `99.9% (One Decimal)`, `99.99% (Two Decimal)` и `99.999% (Three Decimal)`. Больше десятичных знаков выглядит точнее и провоцирует споры о третьем из них; если вы публикуете SLA с тремя девятками, соответствуйте ему и не более того.

У групп есть свои собственные копии этих переключателей — см. ниже — так что группа может показывать агрегированный процент, пока отдельные мониторы внутри неё молчат, или наоборот.

Цвета столбцов графика истории и то, какие статусы монитора считаются «недоступен», задаются на экране брендинга **Overview Page**, описанном в [Оформление и домены страницы статуса](/docs/status-pages/branding-and-domains).

## Группы

Нажмите **New Group**, чтобы открыть **Create New Status Page Group**. Форма состоит из трёх шагов: **Group Details**, **Layout** и **Advanced**.

**Group Details**:

- **Group Name** (`name`) — обязательно. Это заголовок раздела, который видят посетители.
- **Group Description** (`description`) — необязательный markdown, показывается под заголовком.
- **Parent Group** (`parentStatusPageGroupId`) — необязательно. Оставьте значение **No parent group (top level)**, чтобы группа осталась на верхнем уровне.
- **Expand on Status Page by Default** (`isExpandedByDefault`) — начинается ли раздел развёрнутым или свёрнутым для посетителей.

**Advanced** повторяет переключатели ресурса, но на уровне группы:

- **Show Current Group Status** (`showCurrentStatus`) — включено по умолчанию. Показывает статус рядом с заголовком группы.
- **Show Uptime %** (`showUptimePercent`) — выключено по умолчанию, при включении появляется **Select Uptime Precision**.

Редактирование работает так же: **Edit Group** в заголовке панели или **Edit group** в меню строки навигатора открывает **Edit Status Page Group** с кнопкой **Save Changes**.

В заголовке панели показываются чипы для включённых настроек — **Grid**, **Collapsed by default**, **Uptime %**, — так что видно, как настроена группа, не открывая форму.

### Управление группой

Меню строки в навигаторе содержит **Edit group**, **Move up**, **Move down**, **Show ID** и **Delete group**. Переполнение **More actions** на панели содержит более развёрнутые эквиваленты — **Edit this group**, **Add a sub group**, **Move group up**, **Move group down**, **Show group ID**, **Refresh** и **Delete this group**. Группа, сохранённая без имени, отображается как **Untitled group** — верный признак того, что вы забыли что-то ввести.

## Вложенность групп

Группы можно вкладывать: задайте **Parent Group** у дочерней группы или используйте действие навигатора **Add a sub group inside this group**. Подсказка в самой форме описывает форму, для которой она построена, — что-то вроде Corporate Units › Region › Market — и отмечает, что каждый уровень показывает агрегированный статус и аптайм всего, что находится под ним.

Когда у группы есть дочерние элементы, панель ресурсов показывает ряд чипов **Sub groups**, ведущих прямо к каждой дочерней группе, так что вы можете перемещаться по иерархии, не возвращаясь к навигатору.

Вложенность окупается на больших страницах: у хостинг-провайдера с регионами внутри продуктов или у ритейлера с рынками внутри бизнес-подразделений. На странице с двенадцатью мониторами один плоский уровень дружелюбнее.

## Список против сетки

Шаг **Layout** задаёт **View Mode** (`viewMode`) для группы, и от этого зависит, как группа отображается публично.

| Если вы хотите…                                                        | Выберите               |
| ----------------------------------------------------------------------- | ------------------------ |
| Показать простой вертикальный список сервисов, по одному в строке        | **List** (по умолчанию) |
| Показать один и тот же сервис в нескольких регионах или тенантах в виде матрицы | **Grid**                |

Выберите **Grid**, и появятся ещё четыре поля:

- **Row Axis Label** — название измерения строк, плейсхолдер `Service`.
- **Row Axis Values** — сами строки, добавляются по одной кнопкой **Add Row** (плейсхолдер `e.g. Auth`).
- **Column Axis Label** — измерение столбцов, плейсхолдер `Region`.
- **Column Axis Values** — добавляются кнопкой **Add Column** (плейсхолдер `e.g. US-East`).

Каждый монитор в группе с сеткой помещается в ячейку, поэтому модальное окно массового добавления запрашивает строку и столбец вместе с мониторами, используя ваши собственные подписи осей.

**Настройте оси до того, как добавлять мониторы.** Группа-сетка без строк и столбцов показывает жёлтое уведомление о том, что монитор пока некуда поместить, пока не появятся оси, с кнопкой **Set up the grid** — а кнопка **Add Monitor** отсутствует, пока вы этого не сделаете.

## Порядок того, что видят посетители

Порядок задаётся явно, а не по алфавиту, и настраивается в трёх местах:

- **Ресурсы внутри группы** — перетащите строку. Панель прямо об этом говорит: **Drag a row to change the order visitors see**.
- **Группы относительно друг друга** — **Move up** / **Move down** в меню строки навигатора или **Move group up** / **Move group down** в переполнении панели.
- **Ресурсы без группы** — они находятся в **Top of page** и всегда отображаются выше любой группы, так что помещайте туда то, что проверяют в первую очередь все.

**Два случая, когда перетаскивание отключено.** Фильтрация панели полем **Search in {group}...** отключает переупорядочивание — панель сообщает `N of M shown · drag to reorder is off while filtering`, так что сначала очистите поиск. А группы-сетки никогда не поддерживают перетаскивание для упорядочивания, потому что позиция определяется осями строк и столбцов.

Ставьте наверх сервис, о котором спрашивают чаще всего. Посетители, пришедшие на страницу во время сбоя, обычно перестают читать после первого экрана.

## Импорт групп из CSV

Строить глубокую иерархию вручную утомительно. Меню из трёх точек в заголовке карточки содержит **Import groups from CSV**, которое открывает модальное окно **Import Groups from CSV**.

Порядок действий такой: **Download CSV Template**, чтобы получить `status-page-groups-template.csv`, заполните его, **Choose CSV File**, затем **Preview Import**, чтобы проверить, что будет создано, прежде чем что-либо запишется. Результат делится на **Groups Imported** и **Some Groups Could Not Be Imported**, так что плохая строка не исчезает молча.

Обязательно только поле `name`. Поддерживаются следующие столбцы:

| Столбец                    | Что он задаёт                                          |
| ---------------------------- | ---------------------------------------------------------- |
| `name`                       | Имя группы. Обязательно.                                    |
| `parentName`                 | Имя группы, внутрь которой вкладывается эта.                |
| `description`                | Описание группы.                                             |
| `isExpandedByDefault`        | Начинается ли раздел развёрнутым для посетителей.            |
| `showCurrentStatus`          | Показывается ли статус рядом с заголовком группы.            |
| `showUptimePercent`          | Показывается ли процент аптайма рядом с группой.             |
| `uptimePercentPrecision`     | Сколько десятичных знаков использует этот процент.           |
| `viewMode`                   | `List` или `Grid`.                                            |
| `rowAxisLabel`                | Название измерения строк для группы-сетки.                   |
| `rowAxisValues`               | Значения строк для группы-сетки.                              |
| `columnAxisLabel`             | Название измерения столбцов для группы-сетки.                |
| `columnAxisValues`            | Значения столбцов для группы-сетки.                           |

Импорт создаёт группы, а не ресурсы — добавляйте мониторы после этого через **Add Monitor** или **Add Multiple**.
