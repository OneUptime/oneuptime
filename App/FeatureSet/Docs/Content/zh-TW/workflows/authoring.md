# 撰寫工作流程

若要建立工作流程，請開啟 **Workflows** 並點擊 **Create Workflow**。一個名為 **Create a workflow** 的精靈會引導你完成整個流程：先是 **Start from** — 選擇 **Start from scratch** 或某個範本 — 接著是 **Name**，最後是一個 **Configure** 步驟，只有在你所選的範本本身需要設定時，這個步驟才會出現。

建立完成後，在左側選單開啟 **Builder**。那就是你設計工作流程的畫布。

## 畫布

從頭建立的工作流程會以一個寫著 **Please click here to add trigger** 的虛線區塊開啟。那個區塊就是起點 — 點擊它以挑選觸發器。從範本建立的工作流程，開啟時其區塊已經就位。

每個工作流程頂端都恰好有一個 **trigger**。其餘的一切都是會執行某項作業的 **component**。加入第二個觸發器會取代第一個，而刪除最後一個觸發器則會讓虛線佔位區塊重新出現。

加入區塊：

- **觸發器** — 點擊虛線的佔位區塊。一個標題為 **Add Trigger** 的面板會開啟。
- **其他所有項目** — 點擊畫布上方工具列中的 **Add Component**。同一個面板會開啟，標題為 **Add Component**。

這兩個面板都可以搜尋 — 按下 `/` 即可跳到搜尋框 — 並依類別分組。選取一個區塊並點擊 **Add to Workflow**。

新的區塊一律會落在畫布上同一個位置，因此新的一個可能會疊在你已經放置的東西上面。把它拖開；畫布會隨著你拖曳對齊到格線。區塊的位置會被儲存，因此下一個人看到的會是你留下的相同排列。

變更會自動儲存。工具列中的一個藥丸形指示器會追蹤這個狀態：變更傳送中顯示 **Saving…**，接著顯示 **Saved**，若儲存失敗則顯示 **Could not save**。沒有「儲存」按鈕，也沒有另外的發佈步驟。

## 區塊上有什麼

| 欄位                       | 它的作用                                                                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Identifier**（在 **ID** 之下） | 顯示在區塊上的短 id，例如 `log-1`。其他區塊就是靠這個來參照這個區塊，因此重新命名它會破壞每一個指向它的 `{{local.components.…}}` 參照。區塊的標題是該元件本身的名稱，無法變更。 |
| **Settings**               | 該區塊完成其工作所需要的內容 — 一個 URL、一個 Slack 頻道、一段訊息內文。選填欄位會標示為 **(Optional)**；其餘全部為必填。較少使用的設定則收在一個 **Advanced** 的收合區塊之下。 |
| **Input**                  | 位於上緣的圓點，來自先前區塊的線條會連入此處。觸發器沒有這個 — 它們之前不會有任何東西執行。                                                              |
| **Outputs**                | 位於下緣、緊接在其上方標示名稱的圓點，線條會由此連出到下一個區塊。許多區塊有各自獨立的 **Success** 與 **Error** 輸出，讓你可以同時處理這兩種情況。 |

## 連接區塊

從某個區塊底部的圓點拖曳到下一個區塊頂部的圓點。你所繪製的線條決定了接下來執行什麼。

- 如果你從 **Success** 連接，下一個區塊只會在先前的區塊成功時才執行。
- 如果你從 **Error** 連接，下一個區塊只會在先前的區塊失敗時才執行。
- 如果你沒有連接某個輸出，該路徑就會在此停止。

你可以將一個輸出連接到多個區塊。它們全部都會執行 — 但是一個接著一個，在單一佇列中，而不是平行執行。不要依賴分支之間的順序，也不要指望它們在時間上會重疊。每個區塊在每次執行中最多執行一次，因此若連線繞回較早的區塊，該區塊也不會被執行兩次。

## 設定區塊

點擊一個區塊，即可在對話框中開啟它的設定。每個設定都有適合的輸入方式 — 文字欄位、下拉選單、程式碼編輯器、開關等等。填好之後點擊 **Save**。

同一個對話框中還可以找到：

- **Delete** — 移除這個區塊。
- **Run just this step** — 單獨執行這一個區塊，而不執行工作流程的其餘部分。它原本應該從其他步驟讀取的值會是空的，而它所發送、寫入或刪除的任何東西則會真的發生。
- **Documentation**、**Inputs**、**Outputs** 與 **Returns** — 說明這個區塊所需與所產生內容的參考卡片。

大多數文字欄位都接受變數 — 資料就是這樣從一個區塊流向下一個區塊的。與其手動輸入語法，不如使用編輯器中的值選擇器：它會根據你選擇的區塊與欄位，建立出正確的參照。請參閱[工作流程變數](/docs/workflows/variables)。

## 建構時的檢查

Builder 每次你變更整張圖時都會檢查它，並在工具列的一個藥丸形指示器中回報發現的結果。點擊該指示器可開啟 **Problems with this workflow**，其中列出每一個問題，並會跳轉到造成問題的區塊。有問題的區塊在畫布上也會帶有一個紅色徽章。

它會抓出那些原本要等到執行出錯才會顯現的錯誤 — 沒有觸發器、兩個區塊共用同一個 id、id 裡有一個點、沒有任何東西連到的區塊、留空的必填設定、格式錯誤的 JSON、`{{ }}` 內有空格，以及參照到不存在的步驟或回傳值。

有一件事它無法檢查：變數名稱是否存在。改名過的變數只會出現在執行紀錄中。

## 你的第一個工作流程

熟悉這個畫布最快的方式：

1. 點擊虛線的佔位區塊，在 **Add Trigger** 面板中選擇 **Manual**，然後點擊 **Add to Workflow**。
2. 點擊 **Add Component**，選擇 **Log**（在 **Utils** 之下），然後點擊 **Add to Workflow**。把新區塊拖離觸發器，接著把觸發器的 **Execute** 輸出點連接到 Log 區塊的輸入點。
3. 開啟 Log 區塊，把它的 **Value** 設定為 `Hello from {{local.components.manual-1.returnValues.value.name}}`。`manual-1` 是觸發器的 **Identifier**，顯示在觸發器區塊上 — 檢查它是否相符。
4. 前往 **Overview**，在 **Workflow Details** 卡片上點擊 **Edit Workflow**，然後把 **Enabled** 切換為開啟。已停用的工作流程完全無法執行，即使手動執行也不行。
5. 回到 **Builder**，點擊 **Run Workflow**，在 **JSON** 欄位中填入 `{ "name": "Ada" }`，點擊 **Run Workflow Manually**，再以 **Run** 確認。
6. 一個 **Workflow Run** 面板會自動開啟並持續追蹤這次執行。日誌會顯示 `Value:`，後面接著 `Hello from Ada`。

加入、連接、設定、執行、閱讀日誌 — 這個循環就是你建構每一個工作流程的方式。

## 開啟它

新的工作流程一開始是停用的，你複製或匯入的任何工作流程也一樣。

**Enabled** 開關位於工作流程的 **Overview** 頁面上、**Workflow Details** 卡片中 — 而不是在 Settings 頁面上。同一張卡片會以綠色的 **Enabled** 或紅色的 **Disabled** 藥丸形標籤顯示目前的狀態。

已停用的工作流程完全無法執行。手動執行會被拒絕，並顯示「This workflow is not enabled」，就跟被觸發的執行一樣，因此順序是：先啟用它、用 **Run Workflow** 測試它、閱讀執行紀錄，如果你還沒準備好讓它的觸發器實際觸發，就把 **Enabled** 再切回關閉。若只想測試單一區塊而不執行整個工作流程，請使用該區塊設定中的 **Run just this step**。

若要在不刪除的情況下暫停工作流程，把 **Enabled** 切換為關閉。不會有新的執行開始。正在進行中的執行會完成，但停在 **Sleep** 區塊上的執行，會在它甦醒時被取消並記錄為錯誤。

## 整理

- 拖曳區塊以移動它們。版面配置會被儲存。
- 若要刪除一條線，把它其中一端從圓點拖開，放到空白的畫布上。
- 若要刪除一個區塊，點擊它，然後在其設定對話框底部使用 **Delete**。選取一個區塊或一條線並按下 Backspace 也可以移除它。
- 沒有辦法複製單一區塊。工作流程 **Settings** 頁面上的 **Duplicate Workflow** 會複製整個工作流程，而複本會以停用狀態出現。
- 由上到下堆疊區塊，讓它們依照執行的方向被閱讀 — 輸入在上緣，輸出在下緣，因此流程自然會向下走。
