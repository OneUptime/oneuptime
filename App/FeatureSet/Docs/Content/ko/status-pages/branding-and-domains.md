# 브랜딩 및 사용자 지정 도메인

상태 페이지는 고객이 실제로 들여다보는 유일한 OneUptime 화면이므로, 여러분의 것처럼 보이고 여러분의 도메인에서 동작해야 합니다. 이 두 가지는 모두 상태 페이지 사이드 메뉴의 **브랜딩** 섹션에서 설정하며, 여기에 **고급 설정**에 숨어 있는 설정 하나가 더해집니다.

시작하기 전에 알아둘 점은 브랜딩이 일곱 개의 개별 화면으로 나뉘어 있고, 그 구분이 늘 예상한 위치는 아니라는 것입니다. 로고와 표지 이미지는 **필수 브랜딩**이 아니라 **헤더**에 있습니다. 파비콘은 **필수 브랜딩**에 있습니다. 색상은 **개요 페이지**에 있습니다. "테마"라고 생각할 만한 그 밖의 모든 것은 사용자 지정 CSS입니다.

이 페이지는 각 화면을 차례로 살펴본 다음, `status.yourcompany.com`에 페이지를 올리기 위한 CNAME부터 SSL까지의 전체 순서를 안내합니다.

## 각 브랜딩 컨트롤의 위치

상태 페이지를 열면 사이드 메뉴의 **브랜딩** 섹션에 일곱 개 항목이 있습니다. 헤매지 않도록 지도를 그려두면 다음과 같습니다.

| 페이지                     | 그곳에서 설정하는 항목                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| **필수 브랜딩**            | 페이지 제목, 페이지 설명, 검색 엔진 색인, 파비콘.                                          |
| **헤더**                   | 로고, 표지 이미지, 그 대체 텍스트, 헤더 링크 바.                                           |
| **푸터**                   | 저작권 문구와 푸터 링크 바.                                                                |
| **개요 페이지**            | 개요 설명, 기록 차트 막대 색상, 다운타임 상태, 전체 가동 시간 비율.                        |
| **HTML, CSS 및 JavaScript** | 헤더 HTML, 푸터 HTML, 사용자 지정 CSS, 사용자 지정 JavaScript.                             |
| **사용자 정의 도메인**      | 여러분의 도메인, CNAME 검증, SSL.                                                          |
| **언어**                   | 기본 언어와 푸터 전환기에서 제공되는 언어들.                                                |

## 필수 브랜딩

**상태 페이지 → 해당 페이지 → 브랜딩 → 필수 브랜딩** (`{id}/branding`)에는 카드 세 개가 있습니다.

- **제목 및 설명** — 이 카드는 SEO에도 사용된다는 점을 알려줍니다. **편집**을 누르면 **페이지 제목**(플레이스홀더 `Please enter page title here.`)과 **페이지 설명**이 열립니다. 검색 엔진과 링크 미리보기에 표시되는 내용이므로, 팀을 위해서가 아니라 고객을 위해 작성하세요.
- **검색 엔진 색인** — 토글 하나, **상태 페이지 색인을 검색 엔진에 허용**은 Google과 Bing이 이 페이지를 검색 결과에 나열할 수 있는지를 제어한다고 제품 안에서 설명됩니다. 기본적으로 켜져 있습니다. 끄면 페이지가 `noindex, nofollow`와 함께 제공됩니다.
- **파비콘** — **파비콘 편집**을 누르면 **파비콘** 이미지 업로드가 열립니다. 브라우저 탭에 나타나는 작은 아이콘입니다.

다음과 같은 경우에 사용하세요: 페이지가 내부용이거나 아직 설정 중일 때. 완성되지 않은 페이지가 여러분의 브랜드 이름으로 검색 순위에 오르지 않도록 **상태 페이지 색인을 검색 엔진에 허용**을 끄세요.

## 헤더 화면

**상태 페이지 → 해당 페이지 → 브랜딩 → 헤더** (`{id}/header-style`). 사이드 메뉴의 이름과 달리, 여러분의 가장 큰 브랜드 자산 두 가지가 여기 있습니다.

첫 번째 카드는 **Logo, Cover and Favicon**이라는 제목으로, **이미지 편집** 버튼이 있습니다.

- **로고** — 이미지 업로드, 플레이스홀더 `Upload logo`.
- **Logo Alt Text** — 플레이스홀더 `Logo of My Company`. 비워두면 상태 페이지 제목이 대신 사용됩니다.
- **표지** — 이미지 업로드, 플레이스홀더 `Upload cover image`. 헤더 뒤에 있는 넓은 배너입니다.
- **Cover Image Alt Text** — 표지에 대해 같은 개념입니다.

그 아래에는 **헤더 링크** 테이블("Header Links for your status page")이 있습니다. 각 링크는 **제목**과 **링크**(URL, 플레이스홀더 `https://link.com`)를 가지며, 행은 드래그로 순서를 바꿉니다. 아무것도 설정되지 않은 경우 테이블에는 "No status header link for this status page."라고 표시됩니다.

다음과 같은 용도로 좋습니다: 방문자를 여러분의 마케팅 사이트, 문서, 지원 포털로 URL을 추측하게 하지 않고 바로 안내하기.

## 푸터 화면

**상태 페이지 → 해당 페이지 → 브랜딩 → 푸터** (`{id}/footer-style`)는 **헤더**와 같은 형태로, 카드 하나와 테이블 하나가 있습니다.

- **Copyright Info** — **저작권 편집**을 누르면 필드 하나, **Copyright Info**가 열리며 플레이스홀더는 `Acme, Inc.`입니다.
- **푸터 링크** — 동일한 **제목**과 **링크** 쌍이며, 드래그로 순서를 정하고, 비어 있으면 "No status footer link for this status page."라는 메시지가 표시됩니다.

법적 고지, 개인정보 처리방침, 이용약관 링크는 여기에 둡니다. 헤더 링크는 탐색용이고, 푸터 링크는 세부 조항용입니다.

## 개요 페이지 브랜딩

**상태 페이지 → 해당 페이지 → 브랜딩 → 개요 페이지** (`{id}/overview-page-branding`)는 색상을 설정할 수 있는 유일한 화면이며, 차트에서 "다운"이 무엇을 의미하는지도 여기서 결정합니다.

- **개요 페이지** — **브랜딩 편집**을 누르면 마크다운 필드, **Overview Page Description.**이 열리며, 리소스 목록 위에 렌더링됩니다. 이 페이지가 다루는 내용과 지원을 받을 곳에 대한 한 문장 정도의 맥락을 적어 넣으세요.
- **Rules for Bar Colors of History Chart** — 순서가 있고 드래그로 정렬 가능한 규칙 테이블입니다. 각 규칙은 **가동 시간 %가 다음 이상일 때**와 **그러면 이 막대 색상을 사용**을 가지며, 테이블 열은 `When Uptime Percent >=`와 `Then, Bar Color is`로 표시됩니다. 순서가 중요하므로 평가되길 원하는 방식대로 배치하세요.
- **다운타임 모니터 상태** — **Edit Statuses**를 누르면 "These monitor statuses are considered as down"이라고 설명되는 다중 선택이 열립니다. 예를 들어 저하(degraded) 상태가 이 페이지의 가동 시간에 불리하게 계산되는지 여부를 여기서 결정합니다.
- **기본 막대 색상** — **Edit Default Bar Color**를 누르면 **기본 막대 색상** 선택기가 열리며, 어떤 규칙도 일치하지 않을 때 사용되는 색상입니다.
- **전체 가동 시간 백분율** — **Edit Settings**를 누르면 **전체 가동 시간 비율 표시** 토글과 **가동 시간 정밀도 선택** 드롭다운이 열리며, 기본값은 소수점 둘째 자리(`99.99% (Two Decimal)`)입니다.

**차트가 며칠을 다루는지는 여기서 설정하지 않습니다.** 그것은 **상태 페이지 → 해당 페이지 → 고급 → 고급 설정** (`{id}/settings`)의 **가동 시간 기록 표시(일 단위)**이며, 1일에서 90일까지 유효합니다.

## 사용자 지정 HTML, CSS 및 JavaScript

**상태 페이지 → 해당 페이지 → 브랜딩 → HTML, CSS 및 JavaScript** (`{id}/custom-code`)에는 독립적으로 편집 가능한 카드 네 개가 있으며, 상태 페이지의 `headerHTML`, `footerHTML`, `customCSS`, `customJavaScript` 열에 저장됩니다.

- **헤더 HTML** — 플레이스홀더 `Insert Custom HTML here.`, 페이지 헤더에 삽입됩니다.
- **푸터 HTML** — 동일하지만 푸터용입니다.
- **사용자 지정 CSS** — 플레이스홀더 `Insert Custom CSS here.`
- **사용자 지정 JavaScript** — 플레이스홀더 `Insert Custom JavaScript here.`

**테마 선택기는 없습니다.** OneUptime 상태 페이지에는 테마나 브랜드 색상 설정이 없습니다. 어디에도 있는 내장 색상 컨트롤은 **개요 페이지** 화면의 **기본 막대 색상**과 기록 차트 막대 색상 규칙뿐입니다. 글꼴, 배경색, 강조 색상, 레이아웃 조정은 모두 여기 **사용자 지정 CSS**를 통해 이루어집니다. "브랜드 색상" 필드를 찾고 있었다면, 답은 그런 것은 없다는 것이며, 이 상자가 탈출구입니다.

> 사용자 지정 JavaScript는 사람들이 무언가 고장 났을까 걱정하며 정확히 그 순간에 여는 페이지에서, 여러분의 방문자 브라우저에서 실행됩니다. 작게 유지하고, 가능하면 자체 호스팅하고, 의존하기 전에 테스트하세요.

## 언어 설정

**상태 페이지 → 해당 페이지 → 브랜딩 → 언어** (`{id}/languages`)에는 카드 두 개가 있으며, 둘 다 페이지 푸터에서 방문자가 얻는 언어 전환기에 관한 것입니다.

- **기본 언어** — **Edit Default Language**를 누르면 각 지원 언어를 원어 이름과 영어 이름(`Deutsch (German)`)으로 나열하는 드롭다운이 열립니다. 이 카드는 처음 방문하는 사람들이 처음 보게 되는 언어라고 설명하며, 방문자는 언제든 푸터에서 전환할 수 있습니다. 기본값은 영어입니다.
- **활성화된 언어** — **Edit Enabled Languages**를 누르면 다중 선택이 열리며, 플레이스홀더는 `All languages`입니다. 비워두면 지원되는 모든 언어가 제공됩니다. 몇 개만 선택하면 푸터 전환기에는 그것들만 나열됩니다.

OneUptime에는 열여섯 개 언어가 기본 제공됩니다: 영어, 독일어, 프랑스어, 스페인어, 이탈리아어, 포르투갈어, 네덜란드어, 덴마크어, 노르웨이어, 스웨덴어, 러시아어, 일본어, 한국어, 중국어(간체), 중국어(번체), 힌디어.

## 사용자 지정 도메인

기본적으로 상태 페이지는 **개요** 화면에 표시되는 미리보기 URL에서 접근할 수 있습니다. 여러분 자신의 호스트명에 올리려면 **상태 페이지 → 해당 페이지 → 브랜딩 → 사용자 정의 도메인** (`{id}/domains`)으로 이동하세요.

카드 제목은 **Custom Domains**이며, 설명에는 요구사항이 직접적으로 나와 있습니다: 이것이 동작하려면 여러분 설치본의 상태 페이지 CNAME 레코드를 이 도메인들의 CNAME으로 추가해야 합니다. 아무것도 설정되지 않았다면 테이블에는 "No custom domains found."라고 표시됩니다. 테이블에는 **Domain**과 **Status** 두 열이 있고, **Domain**, **CNAME Valid**, **SSL Provisioned** 필터가 있습니다.

### 시작하기 전에

두 가지 사전 조건이 있으며, 둘 중 하나를 건너뛰는 것이 이것이 동작하지 않는 일반적인 이유입니다.

- **상위 도메인이 이미 검증되어 있어야 합니다.** **도메인** 드롭다운에는 프로젝트 설정에서 검증된 도메인만 나열되며, 필드 자체의 도움말 텍스트는 먼저 도메인을 추가하려면 **더 보기 → Project Settings → Custom Domains**를 이용하라고 안내합니다.
- **설치본에 상태 페이지 CNAME 레코드가 설정되어 있어야 합니다.** 자체 호스팅 배포에서는 Docker Compose의 `STATUS_PAGE_CNAME_RECORD` 환경 변수, 또는 Helm `values.yaml`의 `statusPage.cnameRecord`가 이에 해당합니다. 이것이 없으면 **Add CNAME**과 **Order Free SSL** 모달 모두 안내 대신 "Custom Domains not enabled for this OneUptime installation" 메시지를 표시합니다.

### 도메인 추가하기

**Create Status Page Domain**을 클릭하세요. 모달(**Create New Status Page Domain**)에는 두 단계가 있습니다.

**Basic**

- **서브도메인** — 레이블일 뿐이며, 플레이스홀더는 `status (leave blank for root)`입니다. 전체 호스트명이 아니라 `status`만 입력하세요. 루트/에펙스 도메인을 쓰려면 비워두거나 `@`를 입력하세요.
- **도메인** — 검증된 도메인 드롭다운, 플레이스홀더 `Select domain`.

**More**

- **Upload Custom Certificate** — 토글, 기본값은 꺼짐입니다. 꺼둔 채로 두면 OneUptime이 무료 인증서를 대신 주문합니다. 켜면 여러분 자신의 PEM 자료를 위한 **인증서**와 **인증서 개인 키** 필드가 나타납니다.

## CNAME 검증하기

도메인이 아직 검증되지 않은 동안, 행에는 **Add CNAME** 작업이 표시됩니다. 이를 누르면 **Add CNAME**이라는 제목의 모달이 열리며, DNS 제공업체에 붙여넣을 정확한 내용을 알려줍니다.

- **Record Type** — `CNAME`
- **Name** — 방금 만든 전체 도메인, 예를 들어 `status.yourcompany.com`
- **Content** — 여러분 설치본의 상태 페이지 CNAME 레코드

모달에는 레코드가 반영되면 자동 검증에 최대 24시간이 걸릴 수 있다고 나와 있습니다. 그때까지 기다릴 필요는 없습니다. 모달의 제출 버튼은 **CNAME 인증**이며, 즉시 레코드를 확인합니다.

DNS 레코드를 먼저 만든 다음 **CNAME 인증**을 클릭하세요. 레코드가 존재하기 전에 클릭하면 그냥 실패합니다.

## SSL 인증서 주문하기

CNAME이 검증되고 나면 — 그리고 여러분 자신의 인증서를 업로드하지 않았다면 — 행에 **무료 SSL 주문** 작업이 나타납니다. 그 모달인 **Order Free SSL Certificate for this Status Page**에는 OneUptime이 LetsEncrypt를 사용하며, 이 과정이 안전하고 무료이고, 주문 후 프로비저닝에 몇 시간이 걸린다고 설명되어 있습니다. 제출 버튼은 **무료 SSL 주문**입니다.

**화면마다 표시된 시간이 서로 다르므로**, 어떤 하나의 숫자에 너무 의미를 두지 마세요. 주문 모달은 세 시간이라고 하고, **Status** 열은 한 시간이라고 하며, 사용자 지정 인증서는 삼십 분이라고 합니다. 모두 "오늘 늦게 다시 확인하라"는 뜻으로 받아들이고, 그때까지도 아무 일도 일어나지 않았다면 지원팀에 문의하세요.

한 번 프로비저닝되면 갱신은 자동입니다. 여러분이 반복해서 해야 할 일은 없습니다.

## 도메인 Status 열 읽는 법

**Status** 열은 셀 하나에 담긴 설정 상태 기계 전체입니다. 각 메시지는 다음에 무엇을 해야 하는지, 또는 이미 완료되었는지를 알려줍니다.

| Status 열에 표시되는 내용                              | 의미                                                                              |
| ------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Action Required: Please add your CNAME record.         | CNAME이 아직 검증되지 않았습니다. 레코드를 추가한 다음 **CNAME 인증**을 누르세요.  |
| Action Required: Please order SSL certificate.         | CNAME은 검증되었지만 주문된 인증서가 없습니다. **무료 SSL 주문**을 클릭하세요.     |
| No action is required, allow 30 minutes to provision.  | 사용자 지정 인증서를 업로드했고, 설치가 진행 중입니다.                            |
| No action is required, this will be provisioned soon.  | 무료 인증서가 주문되어 진행 중입니다. 반영되지 않으면 지원팀에 문의하세요.        |
| Certificate Provisioned. No action required.           | 완료되었습니다. OneUptime이 인증서를 자동으로 갱신합니다.                         |

DNS 항목을 만든 지 한참 지났는데도 행이 "Action Required: Please add your CNAME record."에 계속 머물러 있다면, 레코드의 이름이 전체 도메인인지, 그리고 그 내용이 여러분 설치본의 CNAME 레코드와 정확히 일치하는지 확인하세요.

## Powered by OneUptime

"Powered by OneUptime" 문구는 브랜딩 섹션의 설정이 아닙니다. **상태 페이지 → 해당 페이지 → 고급 → 고급 설정** (`{id}/settings`)의 **Powered By OneUptime Branding** 카드에, 토글 하나로 존재합니다. **Hide Powered By OneUptime Branding**입니다. 그 페이지의 다른 모든 카드와 마찬가지로 **Edit Settings**를 누르면 열립니다.
